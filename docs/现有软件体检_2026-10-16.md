## 一、优先修（常规操作就会算错或丢数据）

1. **资源库里在不同频段的卫星之间点选，新选中那颗的上/下行频率被改成频段预设并落盘** ✔ 复现
   - 现象：从 Ku 条目点到 C 条目，C 的手填频率被改成 6.15 / 3.95 GHz；约 0.5 s 后落盘，所有引用它的配置都按预设频率算 FSL、增益、雨衰。点回 Ku，Ku 也被改。
   - 原因：编辑器没加 `:key`，同一组件实例换了 form，频段 watcher 把「换条目」当成「改频段」。
   - 修法：三窗卫星编辑器加 `:key="cfg.id"`（或 watcher 先比 form 身份）。
   - 位置：`src/linkbudget/SatellitePanel.vue:61`、`src/linkbudget/LinkBudgetApp.vue:2439`、`src/ngso/NgsoSatellitePanel.vue:132`、`src/regen/RegenSatPanel.vue:178`、`src/components/LbLibrary.vue:166`
2. **C/ASI 上行拿邻星的「下行极化」与本站上行极化比较，出厂配置下上行 C/ASI 多出 25 dB（偏乐观）** ✔ 复现
   - 现象：本站下行 H、上行 V，邻星 H → 上行被判反极化，C/ASI 58.88 dB；不计这一项时为 33.88 dB。
   - 修法：干扰星表加「上行极化」列，留空时沿用下行关系；上行逐源明细补「极化」列。
   - 位置：`src/ci/useInterference.js:89-90,366`、`packages/core/utils/interference/ciAsi.js:451`、`src/ci/ciInputGrids.js:41`
3. **PFD 上行掩模用了页头（下行）的频段；下行按 4 kHz 填时，星间掩模偏低 10 dB** ✔ 复现
   - 现象：出厂四项全开，输出 `Mask_id_3_EIRP_ES_10.7-12.75.xml`，终端增益也按下行频率算。星间作业把 dBW/4 kHz 当成 40 kHz 落盘，偏差落在不安全方向，状态栏和 check() 都不拦。
   - 修法：上行页加独立频段（出厂 14.0–14.5 GHz），λ 从这里取；星间按 `10lg(40/b)` 折合（界面已算出折合值），或把这条偏差纳入 check()。
   - 位置：`src/pfd/PfdMaskApp.vue:208-249`
4. **轨道向导建的地球同步 / 太阳同步 / 回归 / Molniya 星座，每天漂约 1°** ✔ 复现
   - 现象：110.5°E 次日变 109.5°E，30 天后 80.9°E；LTAN 10:30 30 天后变 08:32。地图、信息栏、NGSO / 再生取星、星历导出全部跟着错。
   - 原因：场景历元每天回到当天 08:00，而 RAAN 是建星当天按 GMST / 太阳平黄经折算的惯性值，不会跟着变。此外向导的设计输入不落盘，再编辑会退化成「自定义根数」。
   - 修法：normalize / persist 保留 `design`；场景历元变化时，对经度类和地方时类按新历元重解 RAAN。
   - 位置：`src/viz/constellation/useCustomConstellations.js:64-74,164-171`、`src/viz/constellation/orbitDesign.js:325,379,405`
5. **Ctrl+Z 撤一步，会把之后没进撤销栈的新建和编辑一起抹掉，Ctrl+Y 也找不回** ✔ 复现
   - 现象：撤销会整份回放「标记」快照，而右键加点 / 加站、新建航迹、建链、改名都不入栈。
   - 修法：
     - 把这些写入口都包进 `undoable`（一次描绘一步、建链 startNew→finish 一步）。
     - 兜底：有不经 undoable 的改动落盘时，清空该域的撤销栈。
   - 位置：`src/pages/ConstellationMap3D.vue:12849-12886`（UNDO_DOM）、`:9779`、`:9833`、`:11238`、`src/viz/links/useMapLinks.js:164-277`
6. **星座栏搜索后直接关软件（含自动更新重启），重开时全部卫星集被关，地图上 0 颗** ✔ 复现
   - 原因：「仅显示：搜索」落盘时把 `'q'` 滤掉，visible 变空，`solo.prev` 也丢了。
   - 修法：`solo.id === 'q'` 时把 `solo.prev` 落成 visible；init 读到空可见集时退回出厂集合。
   - 同类：搜索 0 命中后清空搜索框不会还原（clearSearch 早退条件）。
   - 位置：`src/viz/constellation/useSatSets.js:32-40`、`src/pages/ConstellationMap3D.vue:3389-3398`
7. **带贴图的 OBJ / FBX 导入必然失败（GLTFExporter: No valid image data found）** ✔ 复现
   - 原因：导入器没等贴图加载完就返回（`side.cleanup()` 没 await），紧接着导出 GLB，此时贴图 image 还是 null。.mtl 引用的贴图缺失时也走这条报错，注释里说的「缺贴图照样入库并告警」走不到。
   - 修法：返回前等在途贴图加载完（有在途才等）；导出前把 image 仍为 null 的贴图槽置空，并记一条「缺少贴图」。
   - 位置：`src/viz/models/importers.js:164,190`、`src/model/wbStore.js:951-970`
8. **链路表导出 Excel 再导入，收信站一侧整组丢失（GSO / NGSO）** ✔ 复现
   - 原因：发、收两侧同名列（地球站配置、位置、经度、纬度、海拔、R0.01%、可用度，NGSO 还有最低仰角、斜距），导入只认第一列。批量设值下拉同根，有两个「经度」分不清。
   - 修法：导出表头加侧别（「收信站·经度」），导入时同名标签按出现次序对键；批量设值下拉也带组名。
   - 位置：`src/shared/gridXlsx.js:117-141`、`src/linkbudget/StationGrid.vue:1218-1271,1781`（`src/ngso/StationGrid.vue` 镜像相同）
9. **频率分配表「↓中心」格每敲一键就落值** ✔ 复现
   - 现象：改第 2 条及以后的载波，第一键落下后整行被重排到组首、焦点丢失，载波停在 3 MHz，后面的按键全部丢失。
   - 修法：中心格改成迟落（@change / 回车提交，与起、止两格相同）。
   - 位置：`src/freqplan/FpAlloc.vue:828-829`
10. **频率计划改完一格后马上点另一份计划 / 新建 / 复制，这次改动丢失** ✔ 复现
    - 原因：600 ms 防抖到点时存的是当时的 currentId，已经换成新计划了；撤销栈也随换计划清空。
    - 修法：openPlan / createPlan / duplicatePlan 换入前先 `clearTimeout(saveTimer); if (dirty) await doSave()`；beforeunload 先 blur 再存。
    - 位置：`src/freqplan/FreqPlanApp.vue:290-354,467-485,1600`
11. **再生式上行 / 下行的「单程时延」报成两跳之和，是实际值的 2 倍** ✔ 复现
    - 现象：斜距 11000 km 时报 73.4 ms（实际 36.7 ms）、RTT 146.8 ms。详细预算、几何卡、SLA 依据「36.7 + 36.7」、报告都受影响。
    - 修法：上行取 `linkDelayUpResult`、下行取 `linkDelayDownResult`；瀑布行名去掉「端到端」。
    - 位置：`packages/core/utils/linkCalculatorNGSO.js:1499`、`src/regen/RegenLinkBudgetApp.vue:764-770,1195`、`src/shared/lbSla.js:892-920`
12. **导出报告的「报告名称」改过一次后，切到别的卫星仍印旧名** ✔
    - 现象：文件名按新星，封面、Excel 首行、PDF 书签却印旧星。四窗和 SLA 报告都这样。
    - 修法：只有存下的 titleDefault 等于当前默认名时才沿用钉住的名称，否则回到自动名（或者标题跟配置存，空间态势是先例）。
    - 位置：`src/components/LbReportDialog.vue:63,130-134`
13. **交付报告内容错** ✔ 复现
    - 列头：Excel「工况对照（晴空 / 降雨）」和端到端「逐段汇总」的列头印成「上行 | 下行」（`valueHeaders` 只看列数，不看 `seg.heads`）；英文 Word 里这张表列头仍是中文。
    - 输入参数表：印出「物理层参数 = [object Object]」，门限模式印成 ebno / snr；再生上行多印一整块「收信站群」，反而不印「功放功率预设」。
    - 缺图：当前链路计算失败时，含图报告整份没有图，回执只说「已生成」。
    - 修法：
      - 三个渲染器和 TSV 先取 `seg.heads`，builder 用 `b._t` 出字。
      - 输入清单按链路模式取字段组，跳过对象字段，选择项输出显示名。
      - harvestFigures 每切一条链路重取 vizRef。
    - 位置：`electron/services/report.js:503,528`、`packages/core/utils/waterfallBuilder.js:759-778`、`src/shared/lbReport.js:123-145`、`src/shared/useLbReport.js:73-77`
14. **切配置后，详细预算、图表、容量汇总、TSV 仍是上一份的结果（GSO / NGSO）**（读码）
    - 同类：再生式仍能复制出旧 TSV；端到端「输入已变」一直亮。
    - 修法：四窗 applyState 统一清结果态（links / segments / sweepParamsByRow / computedVals）并复位 resultsStale，照再生式 clearModuleResults 写。
    - 位置：`src/linkbudget/LinkBudgetApp.vue:1967-1990`、`src/ngso/NgsoLinkBudgetApp.vue:2107-2131`、`src/regen/RegenLinkBudgetApp.vue:2245-2260`、`src/e2e/E2eLinkBudgetApp.vue:1316-1349`

## 二、其次修（特定但常规的条件下出错，或操作被打断）

### 主窗口 3D 与星座
- **选中集按对象认星**（ConstellationMap3D.vue:3233-3248、2991-2996、3352）
  - 现象：Ctrl+点已聚焦的星、右键「移出聚焦」、搜索下拉里的 ✓，都变成再加一份同号副本，轨迹和覆盖圈画两层。每天首次联网后，聚焦星停在缓存版根数上，「导出星历」导出的也是旧根数。
  - 修法：selectSat / startFollow 按 satIdOf 判重；put() / setSearchPool 换成新对象后，按 satIdOf 重映射 selEntries / selEntry / followEntry。
- **导入的点序列星历星（800000 段）加进卫星组后组里不显示，次日被当「离轨」删除**（ConstellationMap3D.vue:4066）
  - 原因：satGrpSweep 只豁免 ≥900000，与 `customSats.js:33` 的注释不符。
  - 修法：probe 对 800000–899999 返回 null；组成员解析不到时回退 ephAllOwn。
- **文件管理「导入替换」内置星座组后，星座页仍用旧数据，要重启才生效**（FileManager.vue:122-136）
  - 修法：成功后发桥信号，星座页清掉该组缓存并重载。
- **切换 MSAA 后旧页面整份泄漏，而且继续工作**（ConstellationMap3D.vue:13331-13365、perfWinHost.js:419-441、scene.js:4996-5021）
  - 原因：首个 await 之后创建的 6 个 watch 不随组件销毁；perfWinHost 的 IPC 监听不摘；没有 forceContextLoss；撤销栈不清。
  - 后果：每拨一次涨 100–180 MB；跨这次切换按 Ctrl+Z，改的是死页面，并把旧标记写回 localStorage。
  - 修法：watch 挪到 await 前（或收集 stop 句柄）；卸载时调 clearSceneUndo、forceContextLoss。更好的做法是 MSAA 只重建 3D 场景，不整页重挂载。
- **2D「跟随卫星」中点「取消聚焦」，跟随不退出**（ConstellationMap3D.vue:3442）
  - 现象：悬停和单击全被挡住，只能按 Esc 退出。
  - 修法：closeCard 里加 `if (_flatFollowSat) stopFlatFollow()`。
- **可见性分析两处状态保不住**（ConstellationMap3D.vue:8080、4378、13335）
  - 收起侧栏就中止覆盖计算并撤掉热力图，违背「收起侧栏 ≠ 离开视图」。
  - 停在可见性视图、卫星集选了某个卫星组，重启后回退成「当前显示」并写回存档。
  - 修法：进出改看 sideCtx()；satGroups.load 提前同步调用。

### 2D 平面图与地图对象
- **2D 跟随卫星时导出视频，成片里地图一顿一顿**（ConstellationMap3D.vue:6034-6078、useVideoExport.js:483-494）
  - 原因：跟随按墙钟 250 ms 节流，逐帧出帧时没有绕过。
  - 修法：出帧期间每帧按该帧星下点 centerOnSubPt。
- **航迹导出 Excel 再导回，串表**（ConstellationMap3D.vue:11508-11528）
  - 现象：名字带「/」、重名或超过 31 字时，说明表对不上：飞行变航行，速度和出发时刻丢失，同名航迹互相串。
  - 修法：导出前用 `safeSheetName(name, used)` 预先算出表名（MODCOD 表已这样做）。
- **换投影或改画面中心后 2D 回到全图，但缩放条和视图记忆没跟上**（flatCoverage.js:584、ConstellationMap3D.vue:6382-6390）

### 覆盖 / GRD / 波束地图（〔新〕= 今天落地、未实测）
- **〔新〕「导入…」自动分派：第一个认领者即定案，认错了不回落**（importDispatch.js:36-58、importTemplates.js:38、FileManager.vue:742-800）
  - 点过一次「新建脚本」后（起手式写了 `//! match: *.json`），CONSTELLATION_OPT 和 .json 后缀的 GeoJSON 全被这条空脚本截走。
  - 自家 XML 先被当成 KML 解析；含 `"contours"` 的自定义 JSON 先被 GXT-JSON 解析器截走。
  - 修法：内置解析失败、脚本抛错、返回 0 个波束都当作没认出，依次试下一个候选；新建脚本的起手式不写 match。
- **〔新〕无数值档（覆盖边界）的波束导出 KML 后，本软件再导入整份被拒；纯数字波束名被读成 dB**（kml/serialize.js:147-149、kml/parse.js:175-250）
  - 修法：导出时给无数值环写 `level=none` 标记；解析端取不到电平时按 g=null 收下。
- **〔新〕发送到小程序时无数值档以 `g: null` 发出，小程序标注印「null」**（ConstellationMap3D.vue:7311，小程序仓同步改）
- **GRD 多天线同显时，填充 / 线不透明度按聚焦天线全局生效，切换聚焦就跳变**（useGrdCoverage.js:548、1422、2408）
  - 修法：每层带上自己天线的 alpha / lineAlpha。

### 链路预算
- **NGSO / 再生式链路表显示的数不等于入算的数**（ngsoParams.js:116-134、linkCalculatorNGSO.js:341-342、regenParams.js:115-148）
  - 留空格的灰字（最低仰角 10、卫星 G/T 10、再生下行 EIRP 25）≠ 引擎回退值（0°、2 dB/K、46 dBW）。
  - 格内读数与结果列不同源：NGSO 自动最差带雨时，功放尾标 0.183 W，结果列「功放建议」0.048 W。
  - 修法：组参前把留空格补成 f.def，并让 def 与引擎回退对齐；格内读数有结果时直接取引擎出参。
- **端到端编辑后参数被改错**（E2eLinkBudgetApp.vue:235-430、728、776）
  - 改拓扑时链首业务体制被重置成出厂值，端点星 kind 不归一。
  - 在星间跳上插地面转接站后，新的星地跳挂着 23 GHz。
  - 从手动切到自动最差，约一半常用站址报「几何无解」：回填的仰角 toFixed(2) 被当成最低仰角门限。
  - 修法：extendEnd / removeAt 移交 carrier；GSO 回填仰角向下取整到 0.01°。
- **NGSO 卫星的轨道来源在两条路径上丢失**（NgsoLinkBudgetApp.vue:2276、921-936）
  - 分享包里用天线树取的星退成手动圆轨道（GEO 北京例：40586 km @10° vs 37524 km @43.4°）。
  - 导入的星历点序列星，在「从星历搜索」里被拼成空 OMM，报 SGP4 error=2。
  - 修法：sanitize 时有 orbit 就降为 'search'；三处取星走 orbitSpecOf。
- **雨衰页结果与输入不同步**（RainApp.vue:142-144、235-241、330-335）
  - 改输入后曲线按新入参重画，标记点仍是旧结果。
  - 勾「多站汇总」不亮「输入已变」，导出也不补算。

- **OBJ / STL / FBX 同一文件再导入不去重，「概况 · 三角形」恒为 0**（exporter.js:263、wbStore.js:964-977）

  - 原因：分析收尾按开头的快照整份 saveMeta。
  - 修法：postImport 只提交它自己算出的字段。

## 四、值得提升

### 性能
1. **自动更新差量下载从未生效** ✔
   - 证据：updater.log 9/9 次回落整包（COS 不支持多段 Range）。每次下载 224–240 MB，差量本应只要 54–71 MB。
   - 修法：`package.json` 的 build.publish 加 `"useMultipleRangeRequest": false`（一行，从装上该版本之后的下一次更新起生效）；如果不做差量，就停传 blockmap。
2. **PFD 掩模在主进程 ipcMain 里同步计算，计算期间全软件卡死**（`register.js:1961-2057`）
   - 耗时 1.4–13.8 s，还整份回传 9–90 MB 的 XML。
   - 修法：挪进 utilityProcess / worker_threads，接上引擎已有的 onProgress / shouldCancel；只回传统计，XML 由主进程直接写盘。
3. **跟随卫星时按需出帧失效**（`scene.js:4451-4453`）
   - 画面静止也按帧率上限整帧画，老机和核显风扇常转。
   - 修法：live 条件去掉 `!!followDriver`。
4. **2D 导出 PNG / PDF 后，波束地图线一直走 CPU 描边**（`ConstellationMap3D.vue:6691-6724`）
   - 这正是 9 月 2D 卡顿的根因。
   - 修法：exportMap 的 finally 里补一句 `bm.feedFlat(flat)`（一行）。
5. **对星性能表扫过时段后，每一拍都深克隆含 winInfo 的整份快照推给弹窗**（`perfWinHost.js:281-316`）
   - 200 × 10 每拍 30 ms，500 × 12 每拍 91 ms。
   - 修法：winInfo / picks 单独用一个按引用触发的 watch。
6. **渲染端专用依赖打进了 asar，61 MB，占 28%**（`package.json:306-325`）
   - jspdf 28.7 MB，另有 html2canvas、svgcanvas、svg2pdf.js、vue、pinia、d3-geo、earcut、three-mesh-bvh、topojson-client。
   - 修法：挪到 devDependencies。
7. **悬停每 40 ms 重建 1.6 万颗星的身份 Set，并现推聚焦星的 SGP4**（`ConstellationMap3D.vue:13040-13051,3255-3318`）
   - 修法：按 renderEntries 的引用缓存；悬停只用本拍已有的星位。
8. **3D 覆盖层按层号抬升半径（1.0006 + li × 0.00012）**（`scene.js:2987,3120`）
   - 107 束时最上层浮起约 85 km；几十束的 GRD 斜看也有视差。
   - 修法：逐层抬升用很小的常数，或到 8 层左右封顶。
9. **主窗收到任何模型清单广播，都把全部图标组整组重烘、抽稀档清零**（`modelLayer.js:1338`、`iconBatch.js:513,1218`）
   - 工作台每 1.5 s 自动入库一次就触发一次。
   - 修法：跳过 param: / ent: 组；按 mountSig 只重挂真变了的。
10. **失焦降帧把「双屏盯着主窗播放、手在计算窗操作」也压到 10 帧**（`scene.js:398-403,4414`）
    - 修法：改按窗口可见性 / 遮挡判断，或只在时钟暂停时节流。
11. **模型缩略图：缓存命中也要在主线程现生成整颗模型来算签名**（`wbStore.js:314-341`、`modelThumbs.js:96-131`）
    - 87 型星座精模合计约 960 ms；缩略图以 data URL 存在 localStorage。
    - 修法：签名比较挪进 Worker；缩略图改存主进程 thumbs 目录。
12. **波束地图任何样式改动都整份重建两路渲染器**（卡顿程度存疑）
    - 修法：透明度 / 颜色 / 线宽走只改材质的热路径（GRD 已有 restyle*）；2D 期间闸住 3D 通道。

### 交互与健壮性
- **主窗模型库单击卡片就改了主选星的模型绑定，而且换 / 卸模型都不进撤销栈**（`ModelSidePanel.vue:156-159`、`ConstellationMap3D.vue:3670,11123`）

- **〔新〕波束地图多星导入后上图步骤太多**：要逐颗「添加卫星」再逐颗「全选」。修法：加「添加全部」，新加卫星首批次默认全选。另外，重导同一份配置不会清掉已删除的波束。

  - 内置组的行内展开名录不随联网版刷新。
  - 文件管理显示与导出优先用户缓存，与星座页「取较新一份」的口径不一致。

- **报告 PDF 的模型暂存是模块级单槽 `_pending`**：两个窗口几秒内同时出 PDF 会串内容（低频）。
