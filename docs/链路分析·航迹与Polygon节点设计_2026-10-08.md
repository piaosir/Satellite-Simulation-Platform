## 0. 用户原话与落点

| 原话 | 落点 |

## 1. 参照（为什么这么设计）

- **STK Area Target**：面目标有一个质心（Auto Compute Centroid），接入线的终点画在质心；约束按整个面评估，
  Any（任一点满足）/ Whole（全部点满足）两种口径。→ 本稿：质心是缺省代表点；多个代表点时读数报「最差 / 可见数」，即 Whole 口径。
- **STK Chain / Strand**：Chain 里放一个星座，就展开成多条 strand（每条 = 一条具体路径），Complete Chain Access 逐 strand 报。
  → 本稿：一个节点取了 k 个代表点，这条链路就展开成 k 条**支路**；两端都取多点时支路 = 两端点数之积。
- **STK Aircraft / Ship in Chain**：载具是活的节点，位置随场景时刻走。→ 本稿：航迹的「载具」代表点随全局时钟移动。
- **SATSOFT §9.1 Station Grid**：每个 Polygon 的站点 = 质心（Grid Density = 0 时每 Polygon 一个质心站）+ 边界点（Add Border Points，
  就是多边形自己的顶点）+ 区内栅格；站点画在图上，可在图上单击 / 框选逐个改。→ 本稿：质心 / 顶点 / 边界等分三族，图上直接点选。
- **ITU AP30/30A 测试点（test points）**：服务区用一组测试点代表（每个服务区至多 20 个），链路与 PFD 都在测试点上算。
  → 本稿：代表点就是测试点；单个节点上限 64 个（给 20 留足余量），导入时每个代表点成一行。

## 2. 核心概念：代表点 + 支路

- **代表点（representative point）**：面 / 航迹在链路里落成的若干个具体位置，每个点 = 经纬度 + 高度（飞行航迹有高度）+ 名字。
  地球站 / 点标记 / 卫星恒为 1 个代表点（就是它自己）。
- **子跳**：一跳的某一端是多点节点时，这一跳 = 多条子跳（每个代表点一条视线）。
  相邻两个地面端本就不允许（站接站规则），所以一跳最多一端是多点。
- **支路（strand）**：从链首到链尾逐节点各取一个代表点得到的一条具体路径。支路数 = 各节点代表点数之积。
  图上与读数按**子跳**呈现（一跳一束，不按积爆炸）；只有导入才按**支路**展开（一条支路 = 链路预算里一行 / 一条链）。

## 3. 数据（随标记存档 `globe3d/markers.links`，老存档逐字不变）

```
node = { k: 'pg', id, pick: { c?: true, v?: 'all' | int[], d?: N, ds?: int[] } }      // Polygon（id 引用 globe3d/polygons）
     | { k: 'tj', id, pick: { veh?: true, w?: 'all' | id[], d?: N, ds?: int[] } }      // 航迹（id 引用标记层 trajectories）
```

| 字段 | Polygon | 航迹 |
|---|---|---|
| 单点族 | `c` 质心 | `veh` 载具 |
| 离散族 | `v` 顶点：`'all'` = 全部（之后增删顶点自动跟随）/ 下标数组 = 只取这几个 | `w` 航点：`'all'` / 航点 id 数组（航点 id 稳定，插删航点不串位） |
| 等分族 | `d` 边界等分点数 N（2–64）；`ds` 只取其中几个（缺省全取） | `d` 沿迹等分点数 N（含起终点）；`ds` 同左 |

- 缺省取点：Polygon = `{ c }`（质心）；航迹 = 运动档 `{ veh }`（载具），静止档航点 ≤ 16 个 `{ w: 'all' }`，否则 `{ d: 8 }`。
  新建节点时把缺省写进节点（之后航迹定了时间也不会悄悄变口径）。
- 代表点上限：每节点 64 个；超出 → 节点标红（链路无效，不画、不能导入），读数「代表点超过 64 个」。

## 4. 代表点的几何口径（纯函数 `packages/core/models/mapLinkPoints.mjs`，3D 主窗与四窗导入对话框共用）

**Polygon**
- 质心：球面**面积质心**（∫x dA 的方向，按边累加 ½·θᵢ·n̂ᵢ，S2 TrueCentroid 同式）；跨 ±180°、含极点都成立。
  凹多边形的质心可能落在区外（STK 原文也承认）——落在区外时改取**区内距边界最远点**（polylabel，方位等距投影里求），title 注明。
- 顶点：多边形自己的顶点（末点与首点重合的闭合点去掉），编号 顶点 1…n。
- 边界等分：沿闭合边界（大圆边）按弧长 N 等分，从顶点 1 起，编号 边界 1…N。

**航迹**（与载具运动同一条大圆、同一套高度剖面：`trajKinematics`）
- 载具：此刻（场景时钟）的载具位置 + 实际高度；运动档随时钟走，静止档在航迹头（与图上载具同位）。
- 航点：各航点位置 + 实际高度（飞行按剖面）+ 排程时刻（排得出才有），编号 #1…#n（与计算窗「导入站址」的「航迹名#序号」同一叫法）。
- 沿迹等分：按 WGS-84 里程从起点到终点 N 等分（含两端），位置 / 高度取 `trajStateAtS`，名字报里程（如 1,234 km）。

**时间口径**：除载具外，所有代表点都按**此刻**算几何（与地球站同一口径：「终端此刻在这一点时」）；
载具随时钟走，是唯一真正随时间变的端点。航点的排程时刻在点表里显示，点它 = 时间轴跳到该时刻（此时载具正好在那个航点上）。

## 5. 交互

### 5.1 把 Polygon / 航迹放进链路（三条通路，与既有节点同一个插入光标）

1. **图上单击**（插入态）：命中次序 地球站 / 点标记 → 卫星 → 载具 → 航迹线（6 px 内，含航点）→ Polygon 区内（多个嵌套取面积最小的）。
   放进去的取点 = 缺省取点。单击空白处照旧不加；误加一键 Backspace 撤销。
2. **检索框**：根视图新增两组「航迹」「Polygon」（排在点标记之后），按名检索；行上带 航点数 / 顶点数 与该位读数（缺省取点里最差的那个仰角）。
   悬停 = 图上虚线预览各代表点到相邻卫星的视线。光标两侧有地面端时整组不列（同地球站）。
3. **右键**：压在 Polygon 区内 →「从此 Polygon 新建链路」；压在航迹线 / 载具上 →「从此航迹新建链路」；插入态下 →「追加到链路」。

### 5.2 取点编辑器（难点的解法：面板点表 ⇄ 图上直接点选，同一份选择）

节点行在原「属性」位放一枚**取点钮**，显示当前取了什么：`质心`、`顶点 6`、`质心 · 边界 8`、`航点 3/12`、`载具`……
没取到点显示「未选点」（告警色）。点它在节点行下就地展开编辑器（再点 / Esc 收起；同一时刻只开一个，与「更换节点」互斥）：

```
 2  ⬡  华东区                    [质心 · 顶点 3/6 ▾]   ↑ ↓ ×
 ┌────────────────────────────────────────────────────────┐
 │ [质心] [顶点 6] [边界等分 ⎵8⎵]                  4 点   │   ← 族开关（多选），等分族带点数框
 │ ●  质心      31.20°N 121.47°E                  25.1°   │   ← 点表：●已取 ○未取；读数 = 该点到相邻卫星的仰角
 │ ●  顶点 1    32.50°N 119.80°E                  24.0°   │      （低于门限着告警色）
 │ ○  顶点 2    30.10°N 122.30°E                  26.2°   │   单击行 = 取 / 舍该点；悬停 = 图上高亮该点
 │ ●  顶点 3    …                                          │
 └────────────────────────────────────────────────────────┘
```

- 航迹的点表：载具行（读数随时钟跳）、航点行（排程时刻可点 → 时间轴跳过去；飞行航迹报实际高度）、沿迹等分行（报里程）。
- **图上直接点选**：编辑器开着时，该节点的全部候选点画在图上——已取 = 实心圆点、未取 = 空心圈；单击候选点 = 取 / 舍
  （2D / 3D 都行，命中优先于插入光标与选星）；悬停候选点光标变手形。点表悬停的那一点在图上加一圈高亮，反之亦然。
- 族开关整族取 / 舍；离散族逐点取舍后变成「几个」（顶点 3/6），取满自动回到「全部」（之后增删顶点自动跟随）；
  等分点数改了，逐点取舍作废（回到全取）。

### 5.3 图上呈现

- 多点的那一跳画成一束视线（每个代表点一条）：**最差那条**（仰角最低）按链路样式全粗；其余细一档、淡一档
  ——一眼看得出哪一点卡脖子。不可见的子跳照「不可见跳」设置画虚线或隐藏。
- **方向标（2026-10-08 三轮定稿：末端单箭头 + 流动虚线）**：每条（子）跳一枚实心箭头，尖停在终点符号外沿 2 px 处
  （站 / 点 / 载具按图上真实画多大，挂模型的按模型图标外廓；星 / 代表点按链路小圆点）；线身照样画进终点（拓扑上连着），箭头压在线上。
  箭头尾部微凹、1 px 深色衬边，长 6.5 + 2.2w、半宽 2.4 + 1.0w（w = 线宽；细线的箭头相对放大），屏幕像素恒定。
  - 去叠：汇聚束（多个代表点 → 同一颗星）只给最差那条一枚（终点同一个，各条的箭头会在星点前叠成一团）；发散束（星 → 多个代表点）每条一枚，
    2D 再按屏上距离去叠（缩小后挤在一起的不重复画）。
  - 显示 › 方向：**静止**（出厂，只有末端箭头）/ **流动**（可选动效：箭头不动，线身淡底 + 沿信号方向匀速 28 px/s 走的虚线，亮段 10 / 节距 18 px，
    画到箭头尾凹处为止；淡底让线照样连续，与「不可见跳」的断开虚线分得开；不可见的跳不流动、淡一档）/ 关。
  - 导出图、出视频帧一律静止。**不跟系统「减少动态效果」走**：流动是用户在软件里主动选的（出厂静止），而 Windows 关了「动画效果」时
    Electron 恒报 prefers-reduced-motion: reduce —— 首版跟着它降级，用户机器上流动根本动不起来（实测「流动效果没有」）。
    线宽出厂 1.8 → 1.2 px（旧存档仍是 1.8 的跟新出厂走，改过的不动）。
  - 选型依据：Jenny 等 2018（Cartography and GIS，《Design principles for origin-destination flow maps》）——97 幅专业流向图凡表方向的全用箭头，
    每条 2–3 枚的仅 3%、箭头放在线中间的仅 2%；用户实验箭头优于渐细线；原则 = 箭头表方向、按线宽定尺寸且细线放大、箭头不压线不压节点。
    该文引的眼动实验（Netzel 等 2014）里「重复箭头」与「彗星」两种画法表现不好 —— 正是先后被否的 V 标与彗尾 / 光梭。
    流动档 = draw.io「Flow animation」/ React Flow animated edge 的流动边口径。用户在对比台（`.lnkdirharness`，真底图）上看过
    末端单箭头 / 居中单箭头 / 渐细线 / 流动虚线 / 线内脉冲 / 箭头滑行几档后拍板。
  - 被否的中间稿：沿线等距 V 标（一跳一串，支路多了满屏是箭头、乱）；彗尾 / 光梭（浅色底上像串珠子、偏大屏炫光）。
  - 实现：3D = 链路专用屏幕空间线材质 `globe3d/linkLineMaterial.js`（线芯 + 末端箭头 + 流动虚线 + 像素虚线一个 draw call；
    终点符号圆走实例属性 instanceTip，箭头尖在顶点着色器里解一元二次，缩放联动档 uZoomK 每帧回填）；
    2D = 同参数画在画布上（exitBack 从终点往回求走出符号圆的那一点），流动的虚线画在独立叠加画布（自己一条 rAF，不逼整张平面图逐帧重画）。
- 已取的代表点画链路色小圆点（载具点有载具图标，不另画；航迹图层关着时才补点）。
- 飞行航迹的代表点在 3D 里按实际高度起线（与航迹线、载具模型同高）。

### 5.4 读数（纯数字，CLAUDE.md）

- 跳行：单子跳照旧「仰角 · 斜距」；多子跳报「最低–最高仰角 · 可见数/总数」，如 `18.4–25.1° · 7/8`；title 报最差点名、斜距范围。
- 链路详情多一行「支路」：支路数 > 1 才出（导入时就是这么多行）。
- 状态点：任一子跳此刻不可见 = 部分可见（黄）。

## 6. 导入链路预算（推 / 拉两条入口同一个展开函数）

- `mapLinks.linkStrands(link, ctx)`：按支路展开成若干条**单点**载荷——四个计算窗的 `importChains` 收到的仍是老形状（站 / 星节点），
  只多三个可选字段：节点 `altM`（航迹代表点的实际高度，m）、载荷 `grp`（来源链路 id）、`sl`（支路名）。单点链路展开成 1 条、与改前逐位相同。
- 站名 = 对象名 + 代表点名：`华东区·质心`、`华东区·顶点3`、`华东区·边界5`、`航行1#3`、`航行1·载具`、`航行1·1234 km`。
- 各窗：
  - GSO / NGSO：一条支路一行（同改前一条链路一行）。
  - 再生式：逐跳拆行时**同一条链路的各支路里完全相同的行只留一行**（Polygon 8 点 → 星 → 关口站：8 行上行 + 1 行下行，而不是 8 + 8）。
  - 端到端：一条支路一条链，链名 = 链路名 · 支路名。
  - 代表点带高度（飞行航迹）：「海拔」列写实际高度、不再按地形自动取（P.618 / P.676 按站高算，巡航高度上雨衰自然为 0）。
- 每条链路支路上限 512；超出整条跳过（对话框灰显，title 报原因）。导入对话框与推送菜单的计数报「条 / 行」。
