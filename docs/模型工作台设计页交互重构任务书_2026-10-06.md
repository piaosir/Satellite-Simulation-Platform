## 0 用户意图

原话：「进入装配界面后退不回正常模型界面，感觉有点混乱，我最终目的是我可以自定修改现有模型并制造副本，或者自己组装一个卫星/飞机等模型出来；模块的自动吸附效果很差，现在自由度低，没法按用户的想法进行吸附。」

1. **可预期的工作区**：开过的文档都看得见、一键回得去；任何时刻看得见当前在编辑哪份文档、它是模板 / 副本 / 我的件、存没存。
2. **两条主路**：「改现有模型 → 得到我的副本」（模板永不改坏、副本名字明确、不悄悄多出同名件）；「从零组装」。
3. **吸附是助手不是主人**：第一猜测要好，但指针说了算；猜错能一键纠正；要比吸附多一点自由（偏移 / 倾角）时不丢安装关系。

## 1 痛点与根因（摘要；详见诊断）
- N1–N3 P0：设计页靠隐藏、粘滞、本机持久化的 `st.designKind` 二选一；装配视图无任何返回入口；cur 与装配文档两个并行「当前对象」。
- C1 P1：双击模板 = 无声新建同名副本、改一处即入库、再双击又一份；C2 P1：网格模型无副本通道；DM-2：改自己的装配件后原件先被自动覆盖，「另存」得到改后的状态。
- S1 P0 专用接口不限距离、压过命中面、不看正背面（垂尾装到机腹）；S2 P0 候选污染（自由件自身安装接口 24/61）；S3 P0 重新放置抹掉倾角 / 偏置 / 安装接口；S4 面心接口把面中间放件锁成只能滚转；S5 固定像素半径与固定网格；S6 无偏移 / 倾角、要自由就丢锚；S7 方式切换瞬移；S10 派生件不计占用；S11 局部弧回绕；B08 按住拖的判据点不是指针。
- 平台缺陷：模型窗口挂着 Electron 默认菜单（Ctrl+W 关窗、Ctrl+R 重载、单按 Alt 唤菜单栏），且无关窗守卫。

### 3.3 吸附 P0（B 内核 + C 编辑器）

#### 3.3.1 安装语义扩展（core）
- socket / surface / free 三种方式的归一 attach 恒为同一形状：`{mode, socket, face, uv, roll, mount, off, tilt}`；`off = [x, y, z]`（米，**锚系**：socket 为接口系、surface 为面系(uv)；z = 法向偏移，可正可负）；`tilt = [t0, t1]`（度）。不做 flip。
- 位姿：`M = M_父 · A · T(off) · Rz(roll) · Rx(t0) · Ry(t1) · mount⁻¹`（socket / surface）。off 在锚系、滚转与倾角绕件自身安装点 → 先偏移后改滚转，安装点世界位置不变。
- off / tilt 全为缺省（0）时 solvePrimary 走原代码路径、不多乘（保证旧文档逐位不变，含 −0）。热路径零分配约束照守（角度经模块级 Float64Array 传递）。
- **mount 候选**（本件拿哪里去贴）：本件接口 ∪ 本件平面面心（id `@<面 id>`）∪ 本件包围盒六面面心（id `@bbox+X` … `@bbox-Z`）；makeGeo 一次生成 `g.mounts`；solvePrimary / validateAssembly / mountSocketOf / 编辑器 mountSocketFor / occupiedSocketKeys 统一查 g.mounts。'@' 不在接口 id 字符集，不撞名。
- **反解约定**（attachFromWorld / setMode / reparent / splitSym 保位姿）：roll ∈ (−180°, 180°]，t0 ∈ [−90°, 90°]；|cos t0| < 1e-9 时 t1 = 0、转角并进 roll；多解取最接近原值；结果过 clean。性质测试：随机位姿、贴近 90°、柱面锚、局部弧，往返误差 ≤ 1e-9。
- **取锚函数** `pickAnchor(doc, poses, comp, parentId, W)`：新父件上按几何就近：平面（|u| ≤ 1.05·halfU、|v| ≤ 1.05·halfV、|法向距离| ≤ 件尺寸）→ 空闲接口（距离 ≤ max(5 cm, 25% 件尺寸)）→ 局部弧（角度在弧内）→ 都不满足 = 无锚自由（相对父件）。setMode('socket') 只在阈值内选，没有就报「无可用接口。」。
- **setMode / setFree / reparent / splitSym 一律保持世界位姿、按 pickAnchor 保锚**（setFree = 带锚自由：保留 socket / face+uv，t/q 相对锚系）。界面上「方式」仍是 接口 / 面安装 / 自由 三档；模板里的带锚自由件在属性面板显示锚与相对锚系的位置 / 姿态。
- **存档只写非缺省**：入库 / 草稿 / asmHash 前剥掉缺省 off / tilt（旧文档字节与哈希不变）；文档里出现非缺省 off / tilt 时 schema 写 2（旧版本明确拒收，好过错位）。drive.mjs ATTACH_KEYS 加 off、tilt；三方合并保留用户值；原样文档 driveMarks 不变。
- **局部弧不回绕**：面定义判整圆（|2·halfV − 2πr| < 1e-6·r），局部弧 clampIO 夹紧不回绕。
- **占用**：occupiedSocketKeys 计入对称派生件（用主件 id 生成键）；属性面板接口下拉与编辑器同一口径（导出 `freeSocketChoices`）。面心推断前查该面心接口是否已占，占了不推断面心。
- **候选净化**：非根件自己的安装接口不作为落点；与同件平面面心重合的通用接口（accepts=null）不单列为接口候选 —— 由「面心」推断代替（滚转步长沿用该接口的 roll 档），不画其圆环；重新放置时原 attach 为该接口且落点仍是该面心 → 保持原 socket 写法。
- **accepts 收紧**：馈源喇叭 aperture 只收馈源链与副反射面；杆 tip 只收敏感器 / 天线 / 小件；太阳翼铰链方块、地敏方块等机构 / 小件的面不可安装（组件级 `mountableFaces:false` 或面级 accepts）。具体清单由实现方按组件逐个核对后写进组件文件注释。

#### 3.3.2 落点判定新序（编辑器）
1. 判据点 = **指针**（选目标件、选面 / 接口都按指针）；按住拖时 ghost 按抓取偏移跟手，但射线从指针发出（B08）。
2. 指针压在可见接口标记上（半径 = min(22 px, 该件屏上尺寸 × 0.25)）→ 接口。
3. 指针下那一件 E（派生件映回主件）：
   - 专用空闲接口：屏距 ≤ R_ded = clamp(E 屏上尺寸 × 0.3, 24 px, 72 px)，且朝向相机 → 优先；**例外**：E 没有任何安装面、且只有一个兼容专用接口 → 不限距离（馈源进焦点、反射面进座）。背向相机的接口永不自动选（只进 Tab 列表）。
   - 否则命中处在 E 的安装面上 → 面安装（推断 + 网格）。
   - 否则 E 的兼容空闲接口 ≤ 56 px → 接口；否则把命中点投影到 E 最近的安装面（近失、代价加偏置）→ 面安装；否则薄件穿透；否则报「X 无可用安装位」（维持上午口径：反射面 / 太阳翼 / 翼板不作面安装目标）。
4. 空白处：接口 56 px / 平面面近失 36 px 磁吸（用净化后的候选）；否则「未吸附」，松手 = 取消（拖入报「未安装。」，重新放置复位报「未移动。」）—— 不做空白自由放置。
5. 空文档 → 原点（根件），**放下后自动取景**。
- **Shift** = 原样贴（命中面 → 面安装无推断无网格；命中非面 → 贴命中点，结果**带锚**：pickAnchor 取 E 上最近面 / 接口 + off / tilt；空白 → 未吸附）。
- **Tab 候选循环**（放置中）：按下时快照候选列表，按候选身份键（接口 id / 面 id / 推断类型）记住所选；之后每帧只校验它是否仍可行（面候选的 uv 仍跟指针），锁定期间绕过滞回；复位条件：命中件变了、空白锁定后指针移动 > 24 px、所选失效、Shift 切换。一个面只算一个候选（推断点不进循环）；背面接口在列表里。只有 1 个候选时不动作。捕获阶段 preventDefault（不移走焦点）。
- **B（本件安装端循环）**（放置中）：在本件 g.mounts 间循环（库拖入缺省仍按 mountFor 规则；重新放置缺省保持本件当前 mount）。
- 推断半径随屏上尺寸自适应：面心 / 角点 / 边中点推断半径 = min(12 px, 面屏上短边 × 0.12)；线推断 = min(8 px, 面屏上短边 × 0.08)。
- 网格步长新增「自动」= 锚面短边 / 20 取 1-2-5 档（夹 1 mm–1 m）；socket 件与法向偏移以锚面（无面取父件包围盒短边）为基准。新装缺省「自动」；老用户保持原值，除非从未显式设置（加标志位）。功能区显示「自动」时附当前生效值（运行时读数）。
- 重新放置：保留 tilt / off 的法向分量 / mount；换到不同类型落点时面内偏移清零；落点锚与当前相同 → 只改真正变了的量（free 件改 t、surface 改 uv），其余逐位不动；松手点离起点 < 8 px 或按住 < 150 ms → 原样复位（不记撤销、不入库、不分叉）。
- 放置中：右键（buttons 位掩码识别）不移动松开 = 取消，contextmenu 屏蔽到全部按键松开；按住 Alt 移动指针 = 转视角（与空闲态 Alt+左键拖转视角同一修饰键）；窗口 blur / pointercancel = 取消；Ctrl+Tab / Ctrl+W / Ctrl+Z / Ctrl+Y / Delete / Ctrl+D 忽略；1/3/7/0 允许。gizmo 拖动中 1/3/7/0 也屏蔽。
- G / Ctrl+D 点击落位：只认视口与结构树里的点击；点到其它 UI = 取消并放行该点击；从树右键菜单进入时，树行要等指针进过一次视口或离开起始行后才作为落点。
- 双击组件卡片（quickAdd）：选中件无可用位置 → 退到父件 → 根件；autoSlot 查面心占用（占了就不放面心）。
- M 镜像：卫星按件中心主方向挑镜面（±Y 侧 → XZ，±X 侧 → YZ，±Z 面按安装面法向，挑不出退 XZ）；非卫星领域固定 XZ；镜面过本件时报「镜像面过本件。」。状态短语「镜像 XZ」/「镜像 YZ」。
- 光标读数：拖动中跟在指针右下的小读数「目标件 · 接口名 / 面名 · 推断 · i/n · 滚转°」（运行时数据）；视口顶部状态片只留告警与结果短语。专用接口标记实心、通用接口空心。

#### 3.3.3 放下之后（属性面板 + gizmo）
