# 星座交互重设计

## 交互口径

侧栏按用户任务与数据来源分区：自建星座、卫星分组、导入星历、内置星座、场景卫星、目录参考。数据仍由统一注册表管理，每个分区保持原有相对顺序，拖拽与菜单排序限定在分区内。

“全部卫星”改称“全量卫星目录”，与 GEO、空间站、其他星座（内置大型星座以外）归入“目录参考”。它是跨星座的汇总视图，隐藏时默认折叠；显示时保留明确状态，避免用户以为关闭具体星座就能隐藏同样出现在目录里的卫星。数据与可见项不因分类迁移而丢失。

| 控件 | 结果 |
| --- | --- |
| 眼睛 | 切换该项显示，与其他可见项叠加 |
| 名称 | 查看或收起成员，不改变地图 |
| 仅显示此项 | 暂时只显示此项；按钮变“还原”，顶部提供“恢复之前显示” |
| 全部隐藏 | 保存空可见集合，退出单项显示，并保留之前显示供恢复 |
| 搜索框 | 仅查找候选；点击“仅显示匹配卫星”才改变地图 |
| 添加 | 新建卫星组、生成星座、导入星历与目录查找 |
| 删除 | 明确展示行内确认与取消，不再要求用户猜测二次打开菜单 |

行内呈现“显示中 / 已隐藏”，不依赖眼睛斜杠与低透明度区别状态。保存状态来自实际写入结果，失败时显示错误。

## 存档

修复 `initSatSets` 把空可见集合恢复为出厂集合的问题。有效存档中的 `visible: []` 原样恢复；升级补入天线树也不覆盖用户选择的空集合。首次安装仍沿用原有默认显示。

`hiddenSnapshot` 保存“全部隐藏”之前的非临时项目，跨会话可恢复；恢复时过滤已删除项目。搜索临时层不落盘，单项显示搜索结果时继续保存搜索之前的可见集合。搜索候选等待目录完成后读取，并拒绝过时请求回写。

## 常用用途目录（后续调整）

“目录参考”新增 GNSS 导航卫星、气象卫星、地球资源观测卫星、合成孔径雷达（SAR）、空间与地球科学卫星、业余无线电卫星。分类与数据源取自 [CelesTrak 官方分组](https://celestrak.org/NORAD/elements/index.php?FORMAT=csv)，对应 GROUP 为 `gnss`、`weather`、`resource`、`sar`、`science`、`amateur`（地球资源在应用内的键仍为 `earth-resources`）。

这些目录按需加载，接入相同的下载、缓存、云镜像兜底与快照更新机制，不加入开机全量池的批量请求。不同目录可以重叠，地图继续按卫星编号去重。“其他星座”按已登记的具体内置星座取补集，GEO 等轨道目录和新增用途目录不参与排除，避免分类选项反过来改变其成员。
