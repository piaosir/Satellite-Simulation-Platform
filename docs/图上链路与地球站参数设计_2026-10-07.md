## 1. 链路拓扑

一条链路 = 单向有序节点序列 `n0 → n1 → … → nk`（k ≥ 1）。

- 节点两类：**地球站**（引用标记层的站）/ **卫星**（卫星键 satKey ＋ 身份快照）。
- 卫星节点：**透明（弯管）/ 再生**；链端卫星恒为再生（链端没有来波或去处，与端到端引擎同口径）。
- 跳类型由两端推出：站→星 上行、星→站 下行、星→星 星间（**微波 / 激光**，挂在发端卫星上）。
- 中间的地球站 = **地面转接站**（再生节点）。

**有效性**（不满足即「无效」：列表里保留并标红，不画、不能导入；不自动删节点——STK KeepEmptyStrands 思路）：

1. 节点 ≥ 2；
2. 相邻不得同为地球站；
3. 相邻不得为同一对象；
4. 激光星间跳两端须为再生卫星；
5. 引用的地球站已删除 / 卫星无法解析 → 该节点标红。

允许：同一卫星非相邻多次出现（VSAT → 星 → 主站 → 星 → VSAT 的双跳）；首尾同一地球站（环回）。

## 2. 地球站：模型 + 口径 + 天线罩

站对象新增两个可选字段（缺省不写，老存档逐字不变）：`diaM` 天线口径（m）、`radome: true` 有天线罩。

「添加地球站」对话框（右键「添加地球站」，位置取右键处；同一对话框兼作右键「地球站属性…」）：

| 行 | 控件 | 缺省 |
|---|---|---|
| 名称 | 文本 | 地球站 |
| 模型 | 模型选择（复用 ModelPickPop，领域缺省「地球站」） | 上次所选 |
| 天线口径 | 数字 m；空白时灰显模型标称口径 | 模型标称：内置模板 = dims.apertureM；装配件 = 主反射面 diameterM |
| 天线罩 | 复选 | 模型含天线罩组件则勾 |
| 纬度 / 经度 | 数字 | 右键处 |

- 口径跟随：手填优先；换模型时，站口径仍等于旧模型标称（或为空）→ 跟到新模型标称；手填过的不动；卸下模型不清口径。天线罩同理。
- 地球站批量表格加「天线口径 (m)」「天线罩」两列（插在经纬度之前，「末两列 = 经纬度」粘贴约定不变）。
- 列表行：坐标读数可点 → 打开「地球站属性」；悬停 title 报口径 / 天线罩。

## 3. 地球站库对号（四窗统一，纯函数 src/shared/lbStationType.js）

对号键 = **（口径，天线罩）**；站既没口径也没罩 → 不对号，沿用该侧原缺省引用。

1. **找**：口径相等（±1 µm）且带罩与否相同；该侧原缺省引用那份优先，其次库序第一份。
   「带罩」判据 = 条目名含「天线罩 / Radome」——**不给库加字段**，库结构与 GSO 现有存档完全不变。
2. **建**：以该侧缺省条目为底本复制，改口径；带罩 → 上 / 下行「综合损耗」各加该侧工作频率的典型罩损，名「4.5 m 天线罩」；
   不带罩 → 名字交还自动命名（「4.5 m」）。其余射频参数（效率 / 功放 / 馈线 / 噪温 / UPC…）照抄底本，用户在库里改。
3. 典型干燥罩损（出厂值）：<3 GHz 0.1 dB · 3–8 GHz 0.2 · 8–12 GHz 0.3 · 12–18 GHz 0.5 · 18–40 GHz 1.0 · >40 GHz 1.5。
4. 端到端的地球站库没有损耗字段：库条目只按口径对号，罩损加到与该站相邻的上 / 下行跳的「附加损耗」上。

## 4. 交互：活动栏新视图「链路」

同屏一个上下文：链路列表 → 选中链路的检查器 → 显示设置。

- **建链**：视图顶「新建」/ 右键地球站「从此站新建链路」/ 右键卫星「从此卫星新建链路」→ 进入**建链态**：
  在 3D 或平面图上依次单击地球站 / 卫星追加节点；地图顶部横幅「新建链路 · N 个节点」+ 撤销 / 完成 / 取消；
  Enter 完成、Esc 取消、Backspace 撤销；站接站、重复点不追加，状态栏报原因。
  已有链路「图上追加」= 从末节点继续点（STK Extend）。
- **面板里选节点（2026-10-07 三轮，取代「图上追加」）**：建链态推广成一个**插入光标**（`draw.at`）——图上单击与面板检索
  都往光标处插、插完光标后移（STK 对象浏览器指派 + 工作流编辑器「两步之间插入」的合体）。
  - 光标在链路详情竖链里画成一行检索框（WAI-ARIA 组合框）：打字过滤，↑↓ 移动，Enter 选中（检索还在路上就按的 Enter
    等两路结果回来取第一条），选中后不收、清词、光标后移接着挑；空词 Enter = 完成、Backspace = 撤销光标前那个；Esc 先清词再收起。
  - 入口：「新建」（焦点直接进检索框）、竖链末尾「＋ 添加节点」、悬停跳行左侧的「＋」（光标落到这一跳中间）。
    节点名可点 = 就地替换（卫星换卫星时转发方式 / 激光位留在这一位）；站的属性读数可点 = 地球站属性。
  - 候选四组：地球站 · 点标记 · 城市库（选中即在该城市新建地球站）· 卫星（空词 = 常用〔链路里已有 / 聚焦集 / 天线树〕
    + 场景渲染集；有词 = 全量编目检索，同对星跟踪的 satcovSearch）。光标前后有地面端就不列地面端；与邻节点相同的灰显、title 报原因。
  - 每条候选按「放进这一位」算几何（与链路读数同一口径 `viz/links/linkGeom.js`）：可见在前、仰角降序（星间按距离），
    右侧读数仰角 / 星间距离，低于门限着警示色。悬停 / 键盘停留 = 图上预览候选放进去后的两跳（虚线）+ 站的高亮环。
  - 光标行 key 恒为 `slot`：新节点行插在它前面、它本身不挪窝，检索框焦点与节奏不断。
- **列表**：显隐拨杆 · 色块 · 名称（自动名按信号流向「北京站 → 中星 6D → 广州站」，改过即钉住）· 节点数 · 状态色点（全部可见 / 有不可见跳 / 无效）· 勾选框（批量导入）。
- **检查器**：节点竖链。节点行 = 序号 · 类型 · 名称 · 属性（站：口径 · 罩；卫星：透明 | 再生）；跳行 = 上行 / 下行 / 星间（微波 | 激光）+ 实时仰角 · 斜距 / 星间距离；
  节点可删、上下移、插入（地球站列表 / 卫星检索）；底部「生成反向链路」「删除」。
- **显示**：线宽 · 仰角门限（缺省 0°，几何可见）· 不可见跳（虚线 / 隐藏）· 方向箭头 · 名称标注。
- **右键「分析 ▸」**：原「GSO / NGSO 链路预算 · 发信站 / 收信站 / 收发同站」三项删除（由建链取代）；雨衰 / 日凌 / C/I 保留。

## 5. 图上呈现

- 每跳一段视线：3D = 站（地面）↔ 卫星（真实高度）直线（仿 setShellRays 的 fat line）；平面图 = 站 ↔ 星下点大圆弧（跨 ±180° 切段）。
- 每条链路一色（色板轮换，可改）；选中的加粗提亮；不可见的跳按设置虚线变淡或隐藏；跳中点方向箭头。
- 多条链路共用同一跳时按各自颜色分段着色（STK 同口径）。
- 每拍随全局时钟刷新；链路里的卫星解析结果按节点缓存，每拍只做一次 SGP4；读数在小组件里自读，不触发整页重渲染。

## 6. 导入

各窗共用同一个 `importChains()`，两个入口：

- **推**：链路视图勾选 →「导入链路预算 ▾」→ 四个目标（带可导入条数，不适用的提示跳过）→ `tool:open(kind, {links})`。
- **拉**：四个窗口链路表分区工具位加「导入链路」→ 对话框列出图上全部链路（读 `globe3d/markers.links`，同源共享），不适用的灰显、title 报原因 → 勾选导入。

各窗映射（只追加）：

| 窗口 | 一条链路 → | 卫星 | 配置 |
|---|---|---|---|
| GSO | 一行：发信站 = n0、收信站 = n2；两侧地球站库对号 | 天线树 → 星名 → 新建（定点经度） | 同一颗星且当前配置就是它 → 追加；当前「链路级」→ 追加；否则新建配置（多颗星时新配置设「链路级」） |
| NGSO | 同 GSO；最低仰角写缺省值 | NORAD → 天线树 → 星名 → 新建（星历池） | 同 GSO |
| 再生式 | 逐跳拆行：上行 / 星间（微波 / 激光）/ 下行；缺的模块按信号流向补装 | 移植 NGSO 选星 | 追加到当前配置 |
| 端到端 | 一条链：节点 + 跳逐一对应，透明 / 再生、微波 / 激光照搬 | GSO / NGSO 条目按轨道分 | 追加到当前配置 |

当前配置只剩一条未动过的出厂默认行时，导入的行顶替它。
