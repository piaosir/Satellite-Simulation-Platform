# 星座侧栏交互重设计：卫星集（一张有序表）

日期 2026-09-22。发起人：朴东旭。两句原话定了方向：「整个星座区功能很多但是交互很乱，重新设计交互我要最佳实现」；
「内置、卫星组、导入、自定义都变成一个组，顺序可调，全部可编辑，内置的可重置，交互逻辑不是简单优化，而是重新设计」。
**本稿描述的已经是落地版**（`src/pages/ConstellationMap3D.vue` 星座侧栏 + `src/components/SatLayersPanel.vue` + `SatFinderDialog.vue` + `src/viz/constellation/useSatSets.js`）。

---

## 1. 原来为什么乱

同一个侧栏里「点一行」有三种意思：内置分组 = 切换单选（切走会顺手隐藏全部自定义星座）、卫星组 = 进入 / 退出「筛选显示态」、自定义星座 = 切到「无」分组再只显示它；行上小图标最多 8 颗，四段各一套；「地图上现在有什么」没处看；SATCAT 九行常驻筛选表单看不出用途。

## 2. 参照

QGIS / ArcGIS 图层面板（每层同一套控件、多层同显、右键承载次级操作）、STK Object Browser（对象树 + 显隐勾选 + Insert 统一创建）、Blender Outliner（Ctrl/Alt + 眼睛 = isolate，有明确还原入口）、KeepTrack「Find Satellites」（属性筛选是独立对话框，产出结果集再决定显示 / 收藏）。

## 3. 新口径：一切皆卫星集

**实体**：内置星座（CelesTrak 18 组）、卫星组、导入星历组、自定义星座 摊成**一张有序表**，用户眼里只有「卫星集」；搜索结果是钉在最上的临时一行。地图 = 全部可见集的并集（按 NORAD 去重，同号谁优先：自定义星座 > 导入组 > 搜索结果 > 卫星组 > 内置组）。

**每一行同一套控件**：`[拖拽把手] [眼睛] [色块] [种类图标] 名字 · 读数 · 颗数 [⋯] [›]`。改过出厂状态的内置行名字后带一个小点。

**手势只有五个，各种类一样**：

| 手势 | 含义 |
|---|---|
| 眼睛 | 显 / 隐（可多开） |
| Alt + 眼睛，或菜单「仅显示这一集」 | 只看这一集；顶部出现「仅显示：X」标签，点它还原到之前的可见集合 |
| 点行 | 展开 / 收起成员表（虚拟滚动，同一时刻只开一处） |
| 双击行 | 聚焦：转到它那一面并选中（那一集没开就顺手打开，别的集不动） |
| 拖行首把手 | 调顺序，松手落位（菜单里也有 上移 / 下移；「＋」菜单里有「恢复默认顺序」） |

**改名**：双击名字或菜单「重命名」，行内编辑。**改色**：点色块。**成员编辑**：卫星组 = 成员表「加入组 / 移出」+ 「编辑成员…」管理器；内置组 / 导入组 = 成员表「剔除」（覆盖层，菜单「恢复剔除的 N 颗」可撤）；自定义星座 = 「编辑…」进轨道向导。**删除**：任何一集都能删，两步确认（第一次点进入待确认，再开菜单变「确认删除」，5 秒不动自撤）；内置组删掉后从「＋」菜单「找回 · X」回来。**重置**：改过名 / 色 / 剔过星的内置组，菜单出「重置为出厂」。

**「＋ 添加」一个入口**（搜索框右侧）：新建卫星组 / 生成星座…（轨道向导）/ 导入星历文件… / 从目录查找… / 找回删掉的内置星座 / 恢复默认顺序。

**搜索与查找**：搜索框只认名 / 编号，输入即出下拉（点 = 选中并转到；「+」= 攒进选中集），同时「搜索结果」一行钉在最上并自动「仅显示」（顶部标签一点就恢复叠加）；清空关键词即消失。漏斗 = **「查找卫星」对话框**：左栏条件（关键词 + 所有者 / 对象类型 / 状态 / 发射年 + 区制 / 近远地点 / 倾角 / 周期），右栏结果表，动作三颗：显示为图层 / 存为卫星组 / 加入组…。侧栏那九行常驻表单撤掉。

**顶部读数**：`显示 N 颗 · M 集 · OMM 日期`；「惯性视角」「实时」「发送到小程序」三颗 chip 迁走（设置弹窗 / 时间条 / 各集菜单）。

**轨道向导**不变（「仅预览」出厂开 + 种子星自动选中，2026-09-22 `1bd6385`）；新生成的星座自动「仅显示」它。

## 4. 实现落点

| 层 | 文件 | 要点 |
|---|---|---|
| 注册表 | `src/viz/constellation/useSatSets.js` | 只记 **顺序 / 可见集合 / 内置项覆盖层（改名 · 剔星 · 删除标记）**，`localStorage` 键 `constellation3d/satSets`；本体仍在各自的库（`useSatGroups` / `useCustomConstellations` / 主进程 `custom.json` / CelesTrak 组）。内置组颜色沿用 `groupColors`（随设置持久化，渲染取色链直接读它），不存第二份 |
| 面板 | `src/components/SatLayersPanel.vue` | 纯呈现 + 本地 UI 态（改名 / 菜单 / 两步删除 / 拖拽排序）；数据与动作全 emit 给宿主；菜单项由宿主按种类给 |
| 查找 | `src/components/SatFinderDialog.vue` | 条件栏复用 `SatFilterBar`（`expanded` 档），结果表复用 `SatList` |
| 宿主 | `ConstellationMap3D.vue` | `rebuildRenderSet` 改为按可见集拼并集；各类 entries 逐集加载并缓存（`ensureGroup` 缓存优先 + 后台联网、`ensureSatGroupEntries` 按 NORAD 回全量池、`ensureImportEntries` 逐组读记录 / 采样表）；`groupIndex / filterGroupId / soloConst / loadGroup / ingest / showEntries / showNorads / pickGroup / 行右键菜单` 整批删除；旧存档「当前分组」首次启动迁移成可见集 |

验证台：`.layersharness`（launch.json `layers-harness`）挂真组件 + 真注册表 + 假目录，25 条自动检查；`.owizharness` 轨道向导 53 条不受影响。

## 5. 已定的口径（用户未另作答复即按此）

| 事项 | 定 |
|---|---|
| 内置星座从「单选」改「多开」 | 是；「全部卫星」也是一集 |

| 新生成 / 新建 / 找回的集放在哪 | 表最前，且立即可见 |
| 三颗 chip | 迁走 |
