## 1. 现状为什么乱（2026-09-22 逐段核对 `src/pages/ConstellationMap3D.vue` 星座侧栏）

同一个侧栏里，「点一行」有三种不同的意思，用户没法预判：

| 分区 | 点行 | 显示语义 | 行内小图标 |
|---|---|---|---|
| 内置分组 | `pickGroup` 切换当前分组（单选，切走会顺手隐藏全部自定义星座） | 单选 | 展开箭头、取色 |
| 卫星组 | `toggleSatGroup` 进入 / 退出「筛选显示态」（地图只剩这组） | 独占 | 展开、加入、移出、管理、改名、删除、取色，最多 8 颗 |
| 导入星历 | 不响应 | 眼睛叠加 | 展开、种类、眼睛、导出、删除、取色 |
| 自定义星座 | `showConstAlone` 切到「无」分组 + 只显示它 | 独占 | 展开、眼睛、编辑、删除 |

其它：
- 「地图上现在有什么」没有一处能看出来 —— 它是 当前分组 ∪ 可见自定义星座 ∪ 可见导入组 的并集，但一进搜索 / 卫星组显示态就变成「只有命中星」，自定义星座整批消失。
- 搜索框「输入即筛选显示」与 SATCAT 筛选条（九行常驻表单）挤在分组列表之前，筛选条的用途看不出来（用户原话「鸡肋」）：它其实是 STK「Standard Object Database」/ KeepTrack「Find Satellites」那个「从 1.6 万颗里按属性挑星」的查找器，摆在这里像一排永远不知道该填什么的框。
- 「惯性视角 / 相机跟随」「实时开关」「发送到小程序」三颗 chip 放在星座面板顶部，与星座内容无关（前者是视图设置，中者时间条上已有，后者是导出动作）。
- 轨道向导预览与现有星座撞车 —— 已于 2026-09-22 单独修掉（`1bd6385`：「仅预览」拨杆 + 种子星自动进选中集）。

## 2. 参照

- **QGIS / ArcGIS 图层面板**：每层同一套控件（可见性、色块、名称、计数），多层同显，右键菜单承载全部次级操作。
- **STK Object Browser**：对象树 + 每项显隐勾选，属性 / 重命名 / 删除 / Zoom To 都在右键菜单；创建统一走 Insert。
- **Blender Outliner / Photoshop 图层**：Ctrl / Alt + 眼睛 = 只看这一层（isolate / solo），有明确的还原入口。
- **KeepTrack「Find Satellites」**：属性筛选是一个独立对话框，产出一个结果集，再决定「显示 / 加入 watchlist」—— 这正是我们 SATCAT 筛选该有的形态。

## 3. 新口径：一切皆图层

### 3.1 实体

内置星座（18 组）/ 卫星组 / 导入星历组 / 自定义星座 / 搜索结果，统一为 **图层**。地图 = 全部可见图层的并集（按 NORAD 去重，自定义与导入覆盖同号目录星）。

### 3.2 四个手势，各段一样

| 手势 | 含义 |
|---|---|
| 眼睛 | 显 / 隐（可多开） |
| Alt + 眼睛，或菜单「仅显示此层」 | 只看这一层；顶部出现「仅显示：X」标签，点它还原到之前的可见集合 |
| 点行 | 展开 / 收起该层成员表（虚拟滚动 `SatList`，同一时刻只开一处） |
| 双击行 | 聚焦：转到它那一面并选中（等于现在成员表里的「聚焦」） |

其余操作全部收进行尾「⋯」与右键菜单，按图层种类给项：

| 种类 | 菜单 |
|---|---|
| 内置星座 | 仅显示此层 · 聚焦 · 展开成员 ｜ 存为卫星组 · 复制卫星 · 发送到小程序… · 恢复默认颜色 |
| 卫星组 | 同上 ｜ 重命名 · 管理成员… · 加入选中的 N 颗 / 移出 · 复制 · 发送到小程序… · 恢复默认颜色 ｜ 删除 |
| 导入星历 | 同上 ｜ 重命名 · 导出… · 发送到小程序… · 恢复默认颜色 ｜ 删除 |
| 自定义星座 | 同上 ｜ 编辑… · 重命名 · 复制 · 导出… · 发送到小程序… ｜ 删除 |
| 搜索结果 | 存为卫星组 · 关闭 |

删除两步：第一次点「删除」行进入待确认（左侧红条），再开菜单项变「确认删除」，第二次才删；5 秒不动自动撤销。改名：菜单「重命名」或双击名字，行内编辑，回车 / 失焦提交。

### 3.3 搜索与查找

- 搜索框只剩「名 / 编号」：输入即出下拉（点 = 选中并转到；「+」= 攒进选中集），**同时**生成「搜索结果」图层并自动「仅显示」它 —— 与现在「输入即只显示命中星」等效，但状态是显式的（顶部标签写着「仅显示：搜索「xxx」」，点它即恢复叠加）。清空关键词 → 图层消失、还原之前的可见集合。
- 搜索框旁一颗漏斗 = **「查找卫星」对话框**（`SatFinderDialog`）：左栏条件（关键词 + 所有者 / 对象类型 / 状态 / 发射年 + 区制 / 近远地点 / 倾角 / 周期，复用 `SatFilterBar` 的 `expanded` 档），右栏结果表（`SatList`：勾选、Ctrl+A、拖刷），动作三颗：显示为图层 / 存为卫星组 / 加入组…。命中数在标题栏。有条件生效时漏斗高亮。侧栏里那九行常驻筛选表单撤掉。
- 卫星组管理器的搜索复用同一对话框的条件栏。

### 3.4 面板顶部读数

`显示 N 颗 · M 图层 · OMM 日期`（纯数字），右侧是「仅显示：X」标签（有 solo 时才出现）。三颗 chip 迁走：惯性视角 / 相机跟随 → 「地图设置」侧栏（它是 viewPrefs）；实时 → 时间条已有；发送到小程序 → 各图层菜单 + 卫星组 / 导入 / 自定义三个分区头部的「⋯」。

### 3.5 轨道向导

不变（2026-09-22 已改成「仅预览」出厂开 + 种子星自动选中）。在图层模型里它就是一次临时 solo：向导开着时地图只有预览星座；关向导还原。

## 4. 落地改造清单（真页面）

1. **可见集合单一真相**：`visibleLayers: Set<layerId>`（`g:<key>` / `s:<id>` / `i:<id>` / `c:<id>` / `q`）替代 `groupIndex` + `filterGroupId` + `soloConst` + `customConst.visible` + 导入组 `visible` 五处各自为政；`solo = { id, prev }`。持久化 `constellation3d/layers`，旧存档 `selection.groupIndex` → 迁成一个可见的内置层。
2. **渲染集 = 并集**：`rebuildRenderSet` 改为遍历可见层取 entries（内置组按 key 缓存 `Map(key → entries)`，切层不重载；卫星组按 NORAD 从搜索池解析，即现 `showNorads`；导入组按组取记录；自定义星座 `build(cfg)`；搜索层 = 命中记录），NORAD 去重，颜色链不变（逐颗 > 组 > 内置组色 > 默认）。`filterEntries` 那条独占渲染路径删除。
3. **模板**：星座侧栏的搜索 / 筛选条 / chips / 分组列表 / 三个 `.ccsec` 整段换成 `<SatLayersPanel>`，宿主只做 sections / summary / menuItems 的装配与 emit 的落地（现有 `expList` / `expResolve` / `expFocus` / `openRowMenu` 的动作函数基本原样接）。查找对话框挂在 `.g3` 上，`satFilters` / `satcatIdx` / `applyFilter` 改为对话框驱动。
4. **消费方**：可见性分析「当前显示的星」= renderEntries（本就如此）；`VIS_SAT_GROUPS` 下拉不动；小程序发送改为按图层菜单触发；命令索引 `const.filter` → `const.finder`（查找卫星）。
5. **不动**：`GROUPS` 数组（内置组的身份与顺序）、`useSatGroups` / `useCustomConstellations` / `customSats` 数据层、行内展开 `SatList` 与 `useCheckList`、右键菜单的动作实现。
6. 验证：`.layersharness` 的 21 条自动检查改成对真页面抠段（照 `.satedharness/extract.mjs`），另加「切层不重载 / 并集去重 / 旧存档迁移」三条。
