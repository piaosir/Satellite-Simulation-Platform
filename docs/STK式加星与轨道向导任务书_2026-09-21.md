## 0. 一句话目标

把 STK「Insert Satellite」菜单里平台还没有的东西补齐，做成同一套体系：

1. **外部时间标签星历**：STK `.e` 与 CCSDS OEM（KVN / XML）导入导出 → 新传播类型 `ephem`（插值星历，不走 SGP4）；
2. **SP3-c/d 精密星历**导入（IGS / 各分析中心产品，GNSS 全系）→ 复用 `ephem`；
3. **GPS 年历** YUMA / SEM 导入 → 换算成 OMM 记录（走现有 SGP4 通路，零新管线）；
4. **轨道向导**：现有「生成星座」向导升级为 STK Orbit Wizard 同款 —— 九种轨道类型 × 四种布局，参数一动地图上的星、轨道线与 N 圈星下点轨迹就跟着动（对照截图：Type 下拉 / Definition 参数 / Displaying N Rev 预览）；
5. **SATCAT 筛选**：搜索卫星时可按所有者 / 对象类型 / 运行状态 / 发射年 / 轨道区制 / 近远地点 / 倾角 / 周期筛（= STK Standard Object Database 的过滤器），筛出来的批次可直接「存为组」；
6. **星座栏「导入星历」区块**（1–3 的落点，也是上一轮用户明确要的）：导入组逐组一行，显隐 / 改名 / 导出 / 删除 / 配色 / 展开列表 / 右键菜单，与「自定义星座」同款；文件管理仍是权威库，只是多了一个视图；支持把文件拖到侧栏或地图上导入。

不做的部分见 §14。所有新星历进同一条链路：**文件管理库 → 3D 分组与搜索池 → NGSO / 再生 / 端到端窗口**，与现有 OMM 导入完全对等。

### 4.1 core 新模块（纯 CommonJS，主进程 / 渲染端 / Worker 都能用；渲染端照 `ommFormats` 的引法）

| 模块 | 职责 |

### 4.2 数据模型与存储（主进程）

- `custom.json` 的组加 `kind`（缺省 `gp`）、`visible`（缺省 true）、`color`（缺省 ''），`format` 扩到新 id。旧库读回自动补默认（幂等，不写第二份）。
- `kind:'ephem'` 组：`sats:[{ key, name, noradId, objectId, frame, timeSystem, t0, t1, n, interp }]` 只存元数据；采样表另存 `userData/data/ephem/<groupId>.json`（`{ sats:[{ key, t:[…ms], p:[…], v:[…]|null }] }`，写走 `jsonStore.writeJsonAtomic`）。新服务 `electron/services/ephemStore.js`：`save(groupId, sats) / load(groupId) / remove(groupId)` + 内存 LRU（NGSO 引擎每次算都要）。删组时连文件一起删。
- `customSats.importFile(name, text)`：先 `ephemFormats.detectFormat`，命中即走 ephem 分支（SP3 一个文件一组、组内多星）；再 `gpsAlmanac`（yuma/sem → OMM 记录 → 现有 `gp` 组通路，`format` 记 `yuma|sem`）；都不中才走原 `ommFormats`。`raw()`（扁平 CSV，供搜索池）**只吐 gp 组**；新增 `rawVisible()` 供地图：只吐 `visible` 的 gp 组，且每条带 `_group:'ci:'+groupId`。
- 校验：ephem 组每星至少 2 个采样、时间严格递增、位置有限且 |r| ∈ (Re+80 km, 2×10⁶ km)；坏样本剔除并计数；整星无有效样本则丢弃并报错行。

## 6. 项 1：STK `.e` 与 CCSDS OEM

### 6.1 解析（`ephemFormats.js`）

**STK .e**（附录 B 有样例）：首行 `stk.v.x.y`；`BEGIN Ephemeris … END Ephemeris`；关键字大小写不敏感、`#` 注释；支持 `ScenarioEpoch`（UTCG）、`CentralBody Earth`（其它拒收）、`CoordinateSystem`（Fixed / Inertial / ICRF / J2000 / TrueOfDate / MeanOfDate / TEMEOfDate；其它拒收并点名）、`DistanceUnit`（Meters 默认 / Kilometers）、`TimeFormat`（EpSec 默认 / ISO-YMD / UTCG / JDate；其它拒收）、`InterpolationMethod`（Lagrange 默认 / Hermite）、`InterpolationSamplesM1`、`NumberOfEphemerisPoints`（只作校验，不信它）；数据块 `EphemerisTimePos` / `EphemerisTimePosVel` / `EphemerisTimePosVelAcc`（加速度丢弃）/ `EphemerisLLATimePos`（deg deg m → WGS-84 → ECEF）/ `EphemerisLLRTimePos`；`Covariance*` 与未知块整块跳过并计 warning；单文件一星，名字取文件名。

**OEM**（CCSDS 502.0-B-2/B-3）KVN：`CCSDS_OEM_VERS`、`META_START/META_STOP`（`OBJECT_NAME / OBJECT_ID / CENTER_NAME(EARTH) / REF_FRAME / REF_FRAME_EPOCH / TIME_SYSTEM / START_TIME / STOP_TIME / USEABLE_* / INTERPOLATION / INTERPOLATION_DEGREE`）、数据行 `epoch x y z vx vy vz [ax ay az]`（km, km/s）、`COVARIANCE_START…STOP` 跳过、`COMMENT` 不带等号（KVN 老坑）；多段 = 同一星多段拼接（段间不插值，落在缝里返 null）；多个 META 的 `OBJECT_ID` 不同则多星。XML 用 `ommFormats.js` 里那套最小 XML 读取器的思路另写 `oem` 版（`<oem>/<segment>/<metadata>/<data>/<stateVector>`）。`REF_FRAME` 映射：`EME2000|J2000`→J2000；`ICRF|GCRF`→J2000（视同）；`TEME`→TEME；`TOD`→TrueOfDate；`ITRF*|EFG|ECEF|ITRF2000|ITRF2014|ITRF2020`→Fixed；其余拒收点名。`TIME_SYSTEM`：UTC / TAI / TT / GPS / TDB（其余拒收）。

### 6.2 序列化

- `stk-e`：`stk.v.12.0`、`ScenarioEpoch` = 首点 UTCG、`CoordinateSystem` 按 opts（TEMEOfDate / J2000 / Fixed）、`DistanceUnit Kilometers`、`InterpolationMethod Lagrange`、`InterpolationSamplesM1 5`、`EphemerisTimePosVel`，时间 EpSec 6 位小数、位置 9 位有效。
- `ccsds-oem-kvn/xml`：`CCSDS_OEM_VERS = 3.0`、`ORIGINATOR = 卫星仿真平台`、`REF_FRAME` = TEME / EME2000 / ITRF2020、`TIME_SYSTEM = UTC`、`INTERPOLATION = LAGRANGE`、`INTERPOLATION_DEGREE = 5`。
- 回环判据：同格式导入→导出，数值逐位相同（时间到 μs、位置到 1e-9 km）；跨帧导出再导入，`positionAt` 差 ≤ 1 m（内部一致性）。

### 6.3 外部真值（不许只做自洽）

`frames.test.mjs` 用 Vallado 4th ed. Example 3-15 / AIAA 2006-6753 附录同一算例：2004-04-06 07:51:28.386009 UTC，`r_ITRF = (−1033.4793830, 7901.2952754, 6380.3565958) km`，`r_GCRF = (5102.508958, 6123.011401, 6378.136928) km`，`r_TEME = (5094.18016, 6127.64465, 6380.34453) km`。**数字以原文为准**（原文 PDF：celestrak.org/publications/AIAA/2006-6753/AIAA-2006-6753-Rev3.pdf，取不到就按上面这组），容差：J2000→TEME 50 m（原文含 δΔψ/δΔε 修正，我们不含）；TEME→ITRF 1 km（原文含 ΔUT1=−0.4399619 s 与极移，我们忽略）。另加自洽：任一向量 J2000→TOD→TEME→ECEF→…→J2000 回环 ≤ 1 mm。

## 8. 项 3：GPS 年历（YUMA / SEM）

- 解析两种格式（附录 D 字段表）；周号 10 bit → 取与「今天」最接近的整周（写进组 meta，超 5 年给 warning）；`toa` + 周 → GPS 时 → UTC（−18 s，走闰秒表）。
- 换算成 **OMM 记录**（走 `gp` 组、SGP4、可导出六格式）：`MEAN_MOTION = 86400·√(μ/a³)/2π`（a = sqrtA² m→km）、`ECCENTRICITY = e`、`INCLINATION`（SEM：54° + δi·180°；YUMA：rad→deg）、`ARG_OF_PERICENTER`、`MEAN_ANOMALY`、`RA_OF_ASC_NODE` 按附录 D 的 **Ω₀ + GMST(周起点 UTC)**、`EPOCH = toa 的 UTC`、`BSTAR = MEAN_MOTION_DOT = DDOT = 0`、`OBJECT_NAME = GPS PRN nn (SVN mm)`、`NORAD_CAT_ID` 反查 `csv_gps.csv` 的 `(PRN nn)`，查不到用合成号；`Ω̇` 丢弃（SGP4 自算），但校验 |Ω̇_alm − Ω̇_J2(a,e,i)| / |Ω̇_J2| ≤ 5 % 否则 warning。健康位 ≠ 0 照导，计数进 warnings。
- **对拍测试**：`icdPropagate`（ICD-GPS-200 表 20-IV，Kepler 方程 + Ω_k = Ω₀ + (Ω̇ − ω_e)t_k − ω_e·toa，直接出 ECEF）与「换算记录 → SGP4 → ECEF」在 toa ±3 天逐小时对比，**位置差 ≤ 10 km**（预期几 km，J2 短周期）；若超出先查换算不许放宽。附录 D 的 RAAN 两种写法（`Ω₀ + GMST(周起点)` 与 `Ω₀ − ω_e·toa + GMST(toa)`）须相等到 1e-6°。
- STK 的「Load GPS Constellation」联机取历书**不做**（内置 GPS 组已有 TLE；NAVCEN 地址不稳定）；一个年历文件导入 = 一组 = 整星座，导入完成自动切「自定义卫星」分组即等价。

### 9.2 九种类型的输入（逐条对齐 STK OrbitWizard 命令参数，单位换成 km / °）

| 类型 | 输入 | 解出 |
|---|---|---|
| 圆轨道 | 倾角 i、高度 h、Ω | e=0、ω=0、M₀=0 |
| 临界倾角 | 方向（顺行 63.4349° / 逆行 116.5651°）、远地点高度 hₐ、近地点高度 hₚ、升交点经度 λ_AN、ω（默认 270） | a、e；Ω = λ_AN + GMST(t₀)；M₀=0 |
| 临界倾角·太阳同步 | 近地点高度 hₚ、升交点经度 λ_AN、ω（默认 270） | i 强制 116.5651°（顺行无解，title 说明）；由太阳同步条件解 e（1 维求根，e∈[0,0.95)）；Ω 同上 |
| 地球同步 | 星下点经度 λ_ss、倾角 i（默认 0） | a=42164.17 km、e=0、ω=0、M₀=0、Ω = λ_ss + GMST(t₀) |
| Molniya | 远地点经度 λ_a、近地点高度 hₚ、ω（默认 270） | i=63.4349°、T=半恒星日 → a=26561.8 km、e = 1 − (Re+hₚ)/a、M₀=180°（t₀ 在远地点）、Ω = λ_a + GMST(t₀) − atan2(sin u·cos i, cos u)，u = ω+180° |
| 回归轨道 | 倾角 i、回归圈数 k、回归天数 m（整数，非互质给 warning）、近似高度（可选，只用来推荐 k/m）、首个升交点经度 λ_AN | e=0；a 由 k·T_Ω(a) = m·2π/(ω_e − Ω̇(a)) 求根（附录 E）；ω=0、M₀=0、Ω = λ_AN + GMST(t₀) |
| 回归·太阳同步 | k、m、λ_AN、LTAN 或 LTDN（hh:mm） | e=0；T_Ω = m·86400/k 精确；a 与 i 联立（附录 E 定点迭代）；Ω 由地方时（附录 E） |
| 太阳同步 | 倾角 i **或** 高度 h（二选一，另一项解出并回显）、LTAN 或 LTDN | e=0；cos i 公式（附录 E）；h 超上限（≈5 974 km）报错；Ω 由地方时 |
| 自定义根数 | 现有六根数（形状 圆/椭圆、hₚ/hₐ、i、ω、Ω₀、M₀） | 原样 |

所有类型最终都收敛成现有 `params`（`shape/perigeeKm/apogeeKm/incl/argp/raan0/m0` + `pattern/T/P/F`），另存 `design:{ type, inputs }` 供再编辑回显；`generateConstellation` **不改**，只在 `walker.js` 加 `pattern:'single'`（T=1、P=1、名字不加 `-P01-S01` 后缀）。旧存档无 `design` → 视为「自定义根数」。

## 附录 C：插值精度

Hermite 三次（相邻两点位置+速度）误差 ≈ h⁴/384·|r⁗|；LEO r⁗ ≈ n⁴·r ≈ 1e-8 km/s⁴，h=60 s → 3e-4 km。Lagrange-6 对 60 s LEO 同量级；SP3 900 s 采样 MEO（n≈1.5e-4）Lagrange-10 误差 <0.1 m；**LEO 不许用 900 s 采样**（导入时 h·n > 0.3 rad 给 warning）。窗口居中取样，端部退化为单侧。

## 附录 D：GPS 年历字段与换算

YUMA（每星 13 行，`键: 值`）：ID / Health / Eccentricity / Time of Applicability(s) / Orbital Inclination(rad) / Rate of Right Ascen(r/s) / SQRT(A) (m 1/2) / Right Ascen at Week(rad) / Argument of Perigee(rad) / Mean Anom(rad) / Af0(s) / Af1(s/s) / week。
SEM（.al3）：行 1 `N 记录数 名字`、行 2 `周 toa`；每星依次：PRN、SVN、URA、e、δi（半圆，相对 0.30）、Ω̇（半圆/s）、√A、Ω₀（半圆）、ω（半圆）、M₀（半圆）、af0、af1、health、config。半圆 × 180 = 度；i = 54° + δi·180°。
常数（ICD-GPS-200）：μ = 3.986005e14 m³/s²，ω_e = 7.2921151467e-5 rad/s。
**RAAN**：ICD 里 Ω₀ 是「周起点时刻相对格林尼治子午线的升交点经度」，Ω_k(t) = Ω₀ + (Ω̇ − ω_e)(t − toa) − ω_e·toa（ECEF）。惯性 RAAN = Ω_ECEF(toa) + GMST(toa) = Ω₀ − ω_e·toa + GMST(toa) **= Ω₀ + GMST(周起点 UTC)**；两式相等是测试断言。历元 = toa 对应的 UTC。

## 附录 E：轨道向导公式、常数与测试向量

常数：Re = 6378.137 km，μ = 398600.4418 km³/s²，J2 = 1.08262668e-3，ω_e = 7.2921159e-5 rad/s，恒星日 86164.0905 s，平太阳日 86400 s，回归年 365.2421897 d，Ω̇_ss = 360°/365.2421897 d = 0.9856473 °/d = 1.99096871e-7 rad/s，临界倾角 63.4349° / 116.5651°。
n = √(μ/a³)，p = a(1−e²)：
- Ω̇ = −(3/2)·n·J2·(Re/p)²·cos i
- ω̇ = (3/4)·n·J2·(Re/p)²·(5cos²i − 1)
- Ṁ = n·[1 + (3/4)·J2·(Re/p)²·√(1−e²)·(3cos²i − 1)]
- 交点周期 T_Ω = 2π/(Ṁ + ω̇)
- 太阳同步：cos i = −(2/3)·Ω̇_ss·(1−e²)²·a^{7/2}/(J2·Re²·√μ)；给 i 反解 a = [−(3/2)·J2·Re²·√μ·cos i/((1−e²)²·Ω̇_ss)]^{2/7}
- 回归：k·T_Ω(a) = m·2π/(ω_e − Ω̇(a))，初值 a₀ = (μ·(m·86164.0905/k)²/4π²)^{1/3}
- 回归·太阳同步：T_Ω = m·86400/k；迭代 a ← T_Ω→a（含 J2 项），i ← sunSync(a) 至 |Δa| < 1 m
- 平太阳平黄经 L₀ = 280.46646° + 36000.76983·T + 0.0003032·T²（T 为 J2000 起儒略世纪，UT）；LTAN → Ω = L₀ + (LTAN_h − 12)·15°；LTDN → Ω = L₀ + (LTDN_h − 12)·15° + 180°；反推 LTAN = ((Ω − L₀)/15 + 12) mod 24
- 经度 → Ω：Ω = λ + GMST(t₀)（升交点 / 星下点在 t₀ 时）；Molniya 见 §9.2

测试向量（容差见括号）：
- 太阳同步圆轨道 h→i：400→97.03°、500→97.40°、600→97.79°、700→98.19°、800→98.60°、900→99.03°、1000→99.48°（±0.05°）；h=6000 km 报无解
- 地球同步 a = 42164.17 km（±0.05）；λ_ss=110.5° 且 i=0 → t₀ 星下点经度 110.5°（±0.01，通过 SGP4 传播验证）
- Molniya hₚ=500 → a=26561.8 km（±1）、e=0.741（±0.001）、hₐ≈39 870 km；λ_a=100° → 传播到远地点时刻星下点经度 100°（±0.5）
- 临界倾角·太阳同步 hₚ=500 → e≈0.35（±0.02），i=116.5651°
- 回归轨道 Landsat-8：i=98.2°、k=233、m=16 → h≈705 km（±10）；回归·太阳同步 233/16、LTDN 10:00 → i≈98.2°（±0.1）、h≈705（±10）
- LTAN：t₀ = J2000.0 时 L₀ = 280.46646°；LTAN 10:30 → Ω = 257.966°（±0.01）
