## 0. 一句话目标

新增一个独立窗口「**空间态势**」（入口放在工具栏「文件管理」旁边、「文件」菜单里「文件管理…」之后）：从 CelesTrak 取**卫星编目 SATCAT**（全部空间目标的所有者 / 类型 / 状态 / 发射与陨落日期 / 轨道概要）和平台已有的 **GP 星历**（17 个星座组 + `active` 全部在轨），在软件内生成一份可翻阅的**电子报告**，并像链路预算那样有**配置列表**、可**导出 Word 报告**（走现成的《技术文档标准模板》Word 套件）。范围二选一：**全量**（整份编目）或**聚焦我的卫星组**（星座页「卫星组」，可多选）。自定义卫星（自建星座 / 导入组）一律不管。数据获取仍是**众包模式**：不建服务器、不加定时任务，SATCAT 走与 OMM 完全相同的四级链路（当日本地缓存 → CelesTrak 直连 → 腾讯云 COS 众包镜像 → 旧缓存 / 随包内置快照），直连成功的用户 best-effort 回传云镜像，于是云端每天被第一个直连成功的用户刷新一次，其余用户从镜像取。

## 5. 主进程：SATCAT 进众包取数链路

目标：`omm.fetchCsv('satcat', opts)` 与 GP 组同一函数、同一四级链路、同一日志窗格、同一云镜像与内置快照，只是 URL / 判据 / 标签不同。

5.1 `omm.js`
- 新增 `DATASETS = { satcat: { url: 'https://celestrak.org/pub/satcat.csv', label: 'SATCAT 卫星编目', valid: validSatcat } }`；`known = (k) => !!GROUP_QUERY[k] || !!DATASETS[k]`，三处「未知键」守卫改用 `known`（措辞不变）。
- `csvUrl(k)`：`DATASETS[k] ? DATASETS[k].url : 原式`；`validOf(k) = DATASETS[k] ? DATASETS[k].valid : valid`；`readBundled / offlineBest / readCsvRaw / writeCsvRaw / fetchCsvOnce` 里所有 `valid(t)` 改为 `validOf(key)(t)`（GP 键仍是原正则，逐位不变）。`GL(k)` 取 `DATASETS[k].label`。SATCAT 无补充端点（`SUP_FILE` 不加）。
- 日志：直连那行「开始连接 CelesTrak 主端点（gp.php · …）」对 satcat 打印 `pub/satcat.csv`，其余措辞照旧；tag 为 `星历「SATCAT 卫星编目」：`。
- `validSatcat(t)`：首行含 `NORAD_CAT_ID`、`OBJECT_TYPE`、`OPS_STATUS_CODE`、`LAUNCH_DATE`、`DECAY_DATE`；数据行 ≥ 50000（2026-09 实测约 6.6 万）；最后一条非空行按 `splitCsvLine` 拆出恰好 17 列（防截断）。

## 7. 统计引擎 `src/shared/ssaStats.js` 与报告模型 `src/shared/ssaReport.js`

两份都是零 DOM 的 ESM 纯函数，Node 直接 import 测。**所有数只在这里算一次**：屏上电子报告与 Word 都只吃 `ssaReport.buildSsaModel()` 的产物，不各算各的（与 `lbReport.js` 同一原则）。

7.1 `ssaStats.js`（API 与判据，判据全文见附录 C）
- `parseSatcatCsv(text)` → 行数组（字段名见附录 A；数值列转 Number、空 → null；`splitCsvLine` 从 `tle.js` import，名字里有逗号的行是带引号的）。约 6.6 万行，目标 < 300 ms。
- `isInOrbit(row)`、`isDecayed(row)`、`isDeepSpace(row)`、`isActive(row)`、`regimeOf(row)`（用 `classifyOrbit`，无根数 → `'—'`）。
- `buildIndex(rows)` → `Map<norad, row>`。
- `catalogOverview(rows)`：类型 × {在轨, 已陨落, 合计} + 活跃载荷；`regimeTable(rows)`：区制 × 类型（在轨）；`ownerTable(rows, { topN, pin })`：所有者 → {活跃载荷, 在轨载荷, 火箭体, 碎片, 在轨合计, 累计发射, 累计陨落}，按在轨载荷排序，`pin` 的代码（缺省 `PRC`）不足榜也钉进表。
- `launchSeries(rows)`：逐年（1957–今）{载荷, 全部}；`decaySeries(rows)` 同；`monthlySeries(rows, months = 24)`；`inOrbitCumulative(rows)`：逐月在轨对象数（发射 +1、陨落 −1 的前缀和，深空 / 着陆不计）。
- `recentLaunches(rows, days)`、`recentDecays(rows, days)`（载荷与火箭体列明细，碎片只计数）。
- `constellationDeploy(rows, gpUnion)`：按 `CONST_PATTERNS`（`starlink: /^STARLINK/`, `oneweb: /^ONEWEB/`, `kuiper: /^KUIPER/`, `qianfan: /^QIANFAN/`, `guowang: /^HULIANWANG/`, `iridium: /^IRIDIUM/`, `globalstar: /^GLOBALSTAR/`, `planet: /^(FLOCK|SKYSAT|PELICAN)/`, `spire: /^LEMUR/`, `o3b: /^O3B/`, `gps: /^(NAVSTAR|GPS)/`, `beidou: /^BEIDOU/`, `galileo: /^GSAT/`, `glonass: /^COSMOS.*GLONASS|^GLONASS/`）在 SATCAT 里数 {累计发射, 在轨, 活跃, 近 30 天新增, 近 365 天新增, 累计陨落}，在 GP 组里数 {星历颗数} 并做壳层聚类（高度 25 km × 倾角 1° 取前 3）。模式表放 `ssaStats.js` 顶部并注明「以名称前缀近似，与 CelesTrak GROUP 不完全等价」。
- `epochAgeStats(gpRecs, asOf)`：历元龄（天）中位数 / P90 / 最大、> 7 天颗数；按大型星座分组各一行。
- `geoOccupancy(geoGpRecs, satcatIndex, { binDeg: 1, coloTol: 0.2, arc: [60, 150] })`：逐星定点经度（`geoSlotOfOmm` / `geoLonAtEpoch`，只算 `classifyOrbit === 'GEO'` 的）、1° 桶计数、最拥挤前 N 桶、共位簇（相邻经度差 ≤ tol 的连通分量，≥ 2 颗）、重点弧段清单（名称 / 所有者 / 定点 / 状态）。
- 卫星组：`groupResolve(group, gpIndex, satcatIndex)` → 成员分四类：在最新星历中 / 不在星历但 SATCAT 未陨落（附 `missAt`）/ SATCAT 已陨落 / 编目里查无此号；`groupMembers(...)` 成员表字段：名称 · NORAD · 国际编号 · 所有者 · 发射日期 · 在轨天数 · 状态码 · 类型 · 区制 · 近地点 · 远地点 · 倾角 · 周期 · RAAN · 历元 · 历元龄 · RCS · GEO 定点。轨道量**优先取 GP**（历元处根数换算：a 由平均运动、近远地点 = a(1∓e) − Re），无 GP 才退 SATCAT；来源列注明 `GP / SATCAT`。
- `planeClusters(members, { incTol: 1, raanTol: 4 })`：先按折叠倾角 1° 分壳，壳内 RAAN 环形排序、相邻差 > tol 处切分 → 面数、每面颗数（min / max）、面间平均间隔。命名为「轨道面估计（升交点赤经聚类）」。
- `groupVsCatalog(members, rows)`：本组在轨载荷占同区制在轨载荷的比例、所有者构成。
- `geoNeighbors(member, geoGpRecs, { tol: 1.0 })`：GEO 成员 ±1° 内的邻星（名称 / 所有者 / 定点 / Δlon）。
- 排序确定性：并列按 NORAD 升序；全部函数对空输入返回空表不抛错。

## 附录 C：判据（写进报告「口径与判据」表，也是测试断言的依据）

| 项 | 判据 |
|---|---|
| 在轨 | `DECAY_DATE` 为空 且 `ORBIT_TYPE ∈ {ORB, DOC}` 且 `ORBIT_CENTER = EA`（或数字 = 停靠地球轨道母体） |
| 已陨落 | `DECAY_DATE` 非空 或 `ORBIT_TYPE ∈ {IMP}` 且中心为 EA |
| 深空 / 着陆 | `ORBIT_CENTER ≠ EA` 或 `ORBIT_TYPE ∈ {LAN, R/T}`：单独计数，不进区制与所有者表 |
| 活跃载荷 | `OBJECT_TYPE = PAY` 且 `OPS_STATUS_CODE ∈ {+, P, B, S, X}` |
| 区制 | `classifyOrbit`（`src/shared/orbitClass.js`）：e ≥ 0.20 → HEO；同步周期（±2% 恒星日）且 e ≤ 0.01 且折叠倾角 < 5° → GEO；同步周期 → IGSO；a ≤ Re + 2000 km → LEO；其余 MEO。SATCAT 行：e = (APOGEE − PERIGEE) / (APOGEE + PERIGEE + 2Re)，a 由 PERIOD；根数为空 → `—` |
| 近 N 天 | `LAUNCH_DATE / DECAY_DATE ≥ asOf − N 天`（按 UTC 日历日） |
| 在轨龄 | asOf − LAUNCH_DATE（天） |
| 历元龄 | asOf − GP EPOCH（天） |
| GEO 定点 | 历元处 SGP4 一拍星下点经度（`geoSlot.js`），°E 正 °W 负 |
| 共位 | GEO 定点经度按升序相邻差 ≤ 0.2° 的连通分量，≥ 2 颗 |
| 轨道面估计 | 折叠倾角 1° 分壳；壳内 RAAN 环形排序，相邻差 > 4° 处切分 |
| 星座名称模式 | §7.1 `CONST_PATTERNS`，名称前缀近似 |
| 成员四类 | 在最新星历中 / 不在星历但 SATCAT 未陨落（`missAt`）/ SATCAT 已陨落 / 编目查无此号 |
