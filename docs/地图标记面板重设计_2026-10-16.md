# 地图标记面板重设计（2026-10-16）

用户原话：「整个地图标记设置界面看起来非常混乱」→「不够好还是乱，深度设计，我要最优解」。
第一轮只把三节各自整理成「工具条 / 列表 / 样式子面板」，仍是三份重复的大块，被否。本稿换结构。

## 1. 病根

| # | 现象 | 根因 |
|---|------|------|
| 1 | 一屏里同时摊着三层对象的增删改、逐条覆盖、整层样式 | 「数据」与「外观」两种任务混在同一条竖向流里，三节各重复一遍 |
| 2 | 每行 7 件带框控件（拨杆 / 名称框 / 色块 / 模型块 / 两个文字钮 / ×） | 逐条编辑控件常驻在列表行里：100 行就是 700 个框 |
| 3 | 航迹卡片是一张迷你表单（时间 / 航点 / 两个模式钮） | 同上：详情没有地方放，只能塞进行里 |
| 4 | 层级读不出来 | 分区头、子面板头、小标题、勾选从属缩进四种层级记号混用 |

## 2. 成熟软件怎么分

三家同一结构：**对象树 + 选中项的属性检查器**。

- STK：Object Browser（树）→ 右键 Properties Browser（逐对象分页：Basic / 2D Graphics Attributes…）；图形属性可「继承自场景」（InheritFromScenario）——
  对应本软件「整层样式 + 逐条覆盖」。
- QGIS：Layers 面板（勾选显隐、右键按类型给菜单）+ Layer Styling 坞（F7，编辑当前图层，改动即时上图）。
- ArcGIS Pro：Contents 窗格（图层下挂符号小样，随符号改动实时更新）→ 点小样开 Symbology 窗格。

本软件内部的成例：星座侧栏「卫星集」（24px 行：眼睛 / 色块 / 名称 / 计数 / ⋯ 菜单 / 右键同菜单 / 顶部 ＋）。新面板的行与菜单照抄它的外观与手势。

## 3. 结构

```
┌ 顶栏（吸顶）  [搜索名称 / 坐标        ] [⊞] [＋]
├ 对象树
│ ▾ 👁 ●  点标记                       3  ⋯     ← 图层行：显隐 = 整层；计数
│     👁 ●  北京      116.40°E, 39.90°N   ⋯     ← 对象行：小样 = 地图上那枚符号
│ ▾ 👁 📡 地球站       ✥               2  ⋯     ← ✥ = 该层「调整位置」开着（少数态才显形）
│ ▾ 👁 ══ 航迹                         2  ⋯
│     👁 ⛴  航行1  ✎            3 点     ⋯     ← ✎ = 正在绘制该航迹
├ 属性检查器（随选中项）
│ [小样] 北京   点标记 1                [✥][⌖][🗑]
│ 名称 / 纬度 / 经度 ─ 外观：颜色（覆盖 / 跟随图层）/ 3D 模型
└
```

- **选中图层行** → 检查器 = 该层「图层样式」（原三节的样式全部在这里，按 符号 / 标注 / 航迹线… 分组）。
- **选中对象行** → 检查器 = 该对象属性：
  - 点标记：名称、纬度、经度；外观（颜色覆盖、3D 模型）
  - 地球站：名称、纬度、经度；设备（3D 模型、天线口径、天线罩、功放功率 —— 原「地球站属性」对话框的字段就地可改）；天线跟踪（有模型时）
  - 航迹：名称、类型、颜色覆盖、3D 模型；航点（列表 + 按坐标添加）；时间（出发 / 到达 / 历时 / 速度、巡航高度）
- **新建**（顶栏 ＋）：点标记 / 地球站建在画面中心并选中、焦点进名称框（Google Earth「添加地标」口径）；航迹新建即进入绘制。
  地图右键「添加点标记 / 添加地球站…」照旧。

## 4. 行的解剖（24px，与卫星集同一套 token）

| 列 | 图层行 | 对象行 |
|----|--------|--------|
| 展开箭头 | 有（该层无对象时隐去） | 缩进 20px |
| 眼睛 | 常显（淡）；隐藏 = 斜杠眼 + 整行压暗 | 悬停才显；隐藏的常显斜杠眼 + 整行压暗 |
| 小样 | 当前整层符号（点：形状/序号圈；站：天线；航迹：两色线段） | 该对象此刻在图上的样子（含逐条颜色覆盖） |
| 名称 | 图层名 | 用户名；无名显示兜底名（点标记N），淡一档 |
| 读数 | 计数（筛选时 命中/总数） | 坐标（点、站）/ 航点数（航迹），等宽淡色 |
| 状态记号 | ✥ 调整位置开着 | ✎ 绘制中、✥ 调点中 |
| ⋯ | 悬停显形；右键同一份菜单 | 同左 |

**记号加在少数一方**（卫星集 2026-10-06 的判据）：可见是多数 → 不标；隐藏 / 调整位置 / 绘制中是少数 → 标。

## 5. 交互

- 单击 = 选中（树与地图同步：选中对象在图上出选中括号；在图上点中对象 = 树里选中它）。
- 双击对象 = 在地图上定位；双击图层 = 展开 / 收起。
- 键盘（树有焦点）：↑↓ 移动选中，←→ 收起 / 展开，Enter 定位，Space 显隐，Delete 删除（可撤销），F2 改名（焦点进检查器名称框）。
- 删除单个对象 = 立即删 + 「撤销」；删除整层全部 = 菜单两步确认。
- 标题栏搜索「点标记 › 字号」等：定位 = 选中该图层并滚到那一行（panelSections 的分区开启钩子）。

## 6. 落地（2026-10-16）

| 件 | 位置 |
|----|------|
| 对象树 | `src/components/MarkerOutliner.vue`（呈现 + 菜单 + 两步确认 + 键盘；数据与动作 emit 给宿主） |
| 图例小样 | `src/components/MarkLegend.vue`（symbol / badge / station 调地图同一支画笔；航迹行用 Lucide ship / plane —— 俯视船形在 16px 下读成水滴） |
| 树数据 / 选中 / 动作 | `ConstellationMap3D.vue`「地图标记面板：对象树 + 属性检查器」一节（mkTree / mkSel / mkAction …） |
| 检查器 | 同页模板 `.mki`：先三种对象属性页（不打 data-sec），再三个图层样式页（data-sec = mk-points / mk-stations / mk-traj） |
| 标题栏搜索 | `panelSections.registerSecOpener`：分区「打开」= 在树里选中该图层；行定位照旧扫标题后的兄弟节点 |
| 航迹时间 | `TrajTimeFields` 布局 `form`（标签列对齐检查器 .srow）；旧卡片用的 `rows` 已删 |

联动：地图上点中对象 → 树里选中（`selectMapObj`）；「在列表中定位」→ `mkReveal`；右键「航迹时间…」→ 选中该航迹并把焦点给「出发」；
树里选中对象 → 地图出选中括号（`mapSelRing`）；新建 / 进入绘制 / 结束绘制都会把树的选中挪到那条航迹。

## 7. 不做 / 去掉

- 行内常驻的名称框、色块、模型块、编辑 / 调点文字钮、航迹卡片 → 全部进检查器。
- 面板底「清空全部」→ 各图层菜单「删除全部…」（两步确认）。
- 排序拖拽（点标记序号即表格行号，改序走批量表格）。
