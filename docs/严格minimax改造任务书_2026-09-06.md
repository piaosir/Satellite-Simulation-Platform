## 0. 一句话目标

把 `src/viz/grd/synth.js` 里反射面赋形（`buildShapedGrd`）和相控阵赋形（`buildPamShapedGrd`）共用的那套 **IRLS 加权最小二乘启发式**，替换成 **严格 minimax 求解器**：Madsen 派序列线性规划（SLP）+ 信赖域，LP 子问题用 Mehrotra 原对偶内点法；激励取复数；两处共用一个求解器模块。站点栅、Use Polygon Labels、峰值点闭环抬坡、物理定标、GRD 写出、UI 面板 **一律不动**，只换优化内核。

已用原型（附录 A）在同一站点栅、同一波束栅、同一定标口径下验证：中国 11 顶点覆盖、2.4 m 口径 12.25 GHz，覆盖站点最低增益从 IRLS 的 32.62 dBi 提到 33.71 dBi（+1.09 dB），13 轮 SLP，0.57 s。

## 1. 为什么现状不是严格 minimax（改造依据）

`buildShapedGrd` 第 1173–1257 行、`buildPamShapedGrd` 第 1517–1575 行的 `runIters`：

- 每轮解的是加权最小二乘 Σρ_m|f_m − d_m|²，目标场 d = max(当前场, tAmp)（界外 0），权重 ρ ← ρ·exp(0.8·欠额 − 0.12) 夹在 [0.2, 90]。这是 Lawson 式 IRLS 的变体，权重规则、20 分位归一、留优评分 `worstShort·3 + 0.8·bShort + 0.5·sMax` 全是启发式。
- 固定 22/16 轮，没有收敛判据；不保证「最差站余量最大化」，终点没有等纹波活跃集。
- 激励实际恒为实数（代码注释自认「虚部恒 0」），复激励名不副实。
- 增益归一化不在优化环内（定标事后做），优化器看到的余量不是 dBi 余量。

SATSOFT 的做法（手册 §10.2、§10.6.1；二进制符号 `MIN_MAX_MODULE_mp_MMLPA_NEW`、`ITPOINT_MODULE_mp_INTERIOR_POINT_FEASI`、`MINIPOS_PARALLEL_MODULE`；TICRA 官网「不用最小二乘，用 DTU 开发的 minmax 优化器」）：minimax 化为 LP 子问题、内点法求解、迭代到「改善低于阈值或到迭代上限」。初值 Uniform（等幅零相位）或 Uniform Progressive Phase（相位 2πi/N）。这一派的原始文献是 Madsen 1975 与 Hald & Madsen 1981（Math. Programming 20:49–62）。

## 3. 数学定义（求解器的合同）

- 变量：复激励 w ∈ ℂ^N，实化 x = (Re w, Im w) ∈ ℝ^{2N}。
- 站点场：E_m = Σ_j w_j g_{mj}，g_{mj} 为实数（高斯 beamlet 或 `pamField`），只挂 `nbOf[m]` 里的 beamlet（反射面稀疏、PAM 满）。
- 归一化功率：P(x) = xᵀ Q̃ x，Q̃ = blockdiag(Q, Q)，Q 为 N×N 实对称正定。
  - 反射面高斯 beamlet：Q_{jk} = Ω₁ · exp(−ln2 · d²_{jk}/θ₃²)，Ω₁ = π θ₃²/(4 ln2)，d 为 beamlet 中心距，单位全用 deg²（θ₃ 为度）。这是 ∫g_j g_k dΩ 的平面闭式，相邻 beamlet（d = θ₃）重叠 0.5。
  - PAM：理想 Butler 波束正交，Q = Ω_b · I，Ω_b = (180/π)² / (Nx·Ny·dxWl·dyWl) deg²（= λ²/A）。
- 站点增益（相对，dB）：f_m(x) = 10·log10(|E_m|² / P(x))。它对 x 的整体缩放不变，这是 SLP 能工作的前提。
- 目标电平：G_ref = −10·log10(Ω_cov)，Ω_cov 用 `_shapedPrep` 已算好的 `omegaDeg2`。理想平顶在这一归一化下正好是 G_ref。
  - contour 站（kind 0/1）：T_m = G_ref + tdb[m]；残差 r_m = T_m − f_m。
  - sidelobe 站（kind 2）：T_m = G_ref + SUP_DB；残差 r_m = f_m − T_m。
- 问题：min_x max_m r_m(x)。手册 §10.2 的「余量」= −r_m；最差余量站就是 r 最大的站。
- 权重：全部 1（SATSOFT 生成栅时站点同权；`Rel Weight` 是 POS 才用的字段）。边界站不再单独加权（IRLS 里 ρ=2 的做法删掉）。
- 梯度（K = 10/ln10，p₂ = max(|E_m|², 1e-30·P)）：
  - ∂f_m/∂Re w_j = K·(2·Re E_m·g_{mj}/p₂ − gP_j)，∂f_m/∂Im w_j = K·(2·Im E_m·g_{mj}/p₂ − gP_{N+j})
  - gP = 2·Q̃x/P（对全部站点相同的稠密向量，这是第 5.3 节秩一装配的依据）
  - ∇r_m = −∇f_m（contour）或 +∇f_m（sidelobe）
- 不可达站点：现有「contour 站 1.15·θ₃ 内无 beamlet 则剔除并计 unreach」照旧。

## 4. 算法

### 4.1 外环：SLP + 信赖域（Madsen 1975；Hald–Madsen 1981 第一阶段）

```
x ← x0；归一 xᵀQ̃x = 1
F ← max_m r_m(x)；Δ ← 0.5 · max_j |x_j|
for k in 0 .. maxIter−1:
    装配 LP（4.2），解得步 h 与线性预测值 t_lin
    pred ← F − t_lin                      # 信赖域内线性模型能给的最大改善
    if pred < tolDb: 停（收敛）            # tolDb = 0.01 dB
    x_try ← x + h；F_try ← max_m r_m(x_try)
    act ← F − F_try；ρ ← act / pred
    if act > 0: x ← x_try；归一 xᵀQ̃x = 1；F ← F_try   # 归一不改 f，只是防尺度漂移
    if ρ < 0.25: Δ ← Δ/4
    elif ρ > 0.75 and ‖h‖∞ ≥ 0.9·Δ: Δ ← 2Δ
    if Δ < 1e-9: 停
返回 x、F、残差 r、活跃站数（r_m ≥ F − 0.02 dB 的站数）、迭代/接受次数、LP 总步数、是否收敛
```

参数缺省：`tolDb = 0.01`，`maxIter = 60`（N > 250 时 40），`lpMaxIter = 60`。全部确定性，不用随机数。

### 4.2 内环：LP 子问题与 Mehrotra 原对偶内点法

变量 z = (h ∈ ℝ^{2N}, t)，n = 2N + 1。LP：

```
min t
s.t.  r_m + ∇r_m · h ≤ t          （每站一行：[∇r_m, −1]·z ≤ −r_m）
      −Δ ≤ h_j ≤ Δ               （4N 行界约束）
```

标准形 min cᵀz s.t. Az ≤ b，c = e_t。内点法迭代（预估–校正）：

- 原始可行残差 r_p = b − Az − s，对偶可行残差 **r_d = −c − Aᵀy**（y ≥ 0，s ≥ 0）。★ 对偶符号必须是 Aᵀy = −c；写成 +c 时 t 列要求 Σ(−y_m) = 1 而 y ≥ 0，LP 永不收敛，原型首跑就栽在这里。
- 法方程：(Aᵀ D A) Δz = r_d − Aᵀ[(r_c − y∘r_p)/s]，D = diag(y/s)；Δs = r_p − AΔz；Δy = (r_c − y∘Δs)/s。
- 预估步 r_c = −y∘s，取最大可行步长得 μ_aff，σ = (μ_aff/μ)³；校正步 r_c = σμ − y∘s − Δy_aff∘Δs_aff。
- 步长 0.995 倍最大可行步，原始、对偶分开取。
- 初值：h = 0，t = F + 1（所有站行松弛 ≥ 1，严格可行），界行松弛 = Δ，y = 1。
- 停机：μ < 1e-9·(1 + |t|) 且 ‖r_p‖∞ < 1e-8 且 ‖r_d‖∞ < 1e-8；或到 `lpMaxIter`。未收敛时只要 Az ≤ b + 1e-6 仍返回 z（外环的实际/预测比会兜住），并计入 `lpFail` 统计。
- 法矩阵 Cholesky 失败 → 对角加 reg·(1 + |N_aa|)，reg 从 1e-12 起每次 ×100，最多 8 次。
- 终解的 y_m 在活跃站上为正、Σy_m = 1（minimax 乘子归一），可作调试断言。

### 4.3 法矩阵装配：稀疏 + 秩一（性能关键）

站行 m 的系数向量（去掉 t 列）：v_m = s_m·(S_m − K·gP)，s_m = −1（contour）/ +1（sidelobe），S_m 只在 `nbOf[m]` 的 Re/Im 位置非零（反射面每站约 13 个 beamlet → 26 个非零）。令 d_m = y_m/s_m，则

```
N_hh = Σ_m d_m S_m S_mᵀ                         # 稀疏部分，O(M·k²)，k = 2·|nbOf[m]|
       − u cᵀ − c uᵀ + σ c cᵀ                    # 三次秩一更新，O(n²)；c = K·gP，u = Σ_m d_m s_m S_m，σ = Σ_m d_m
N_ht = −Σ_m d_m v_m = −(Σ_m d_m s_m S_m) + (Σ_m d_m s_m)·c
N_tt = Σ_m d_m
界行：N_jj += d_bound(+) + d_bound(−)
```

然后稠密 Cholesky O(n³/3)。同理 A·z、Aᵀ·v 也按「稀疏 + 秩一」算，不要物化稠密 A。反射面 N ≤ 360 → n ≤ 721，Cholesky 约 0.15 s/步，这是上限工况；典型 N = 61 时全程 < 1 s。PAM 满装配时 S_m 稠密，走稠密路径即可。

### 4.4 初值与复激励（用户已拍板）

Uniform（SATSOFT 缺省：等幅零相位）叠确定性对称破缺：Re w_j = 1，Im w_j = 0.05·(−1)^j。理由：g 为实数时，纯实初值下 ∂f/∂Im w 恒为 0，实子空间是 SLP 的不动点，复激励永远进不来；原型实测复解比实解再多 0.25~0.4 dB。不要用随机数（输出须逐字节确定）。

### 4.5 与峰值点闭环抬坡的接口

现有抬坡块（1283–1312 与 1596–1625）只改目标 `tdb`/`tAmp` 后热启动续跑。改造后：求解器对象暴露 `setGoals(T)` 与 `run(extraIter)`，抬坡块改 `T_m += extra·(hb[m]/maxHB)` → `solver.setGoals(T)` → `solver.run(20)`（信赖域重置为 0.25·max|x_j|）。抬坡逻辑本身一行不改。

### 4.6 不做的事

- 不做 Hald–Madsen 第二阶段拟牛顿（SLP 第一阶段对本问题足够；原型 13 轮收敛）。
- 不做穹顶抑制（用户拍板接受：严格 minimax 只抬最低点，区内自然拱起，SATSOFT 同款语义）。
- 不动站点栅、Use Polygon Labels、定标 ⑤、GRD 格式（纯 ASCII 表头、`fexp` 数值形、`SYNTHMETA` 在 `++++` 前）、PAM 激励指令 ⑦ 的 ψ_p 补相位。
- 不放 Worker（一期同步；用户拍板）。不引入第三方依赖。

function cholFactor(A, n) { for (let i = 0; i < n; i++) for (let j = 0; j <= i; j++) { let s = A[i * n + j]; for (let k = 0; k < j; k++) s -= A[i * n + k] * A[j * n + k]; if (i === j) { if (!(s > 1e-300)) return false; A[i * n + i] = Math.sqrt(s) } else A[i * n + j] = s / A[j * n + j] } return true }
function cholSolve(L, b, n) { const x = Float64Array.from(b); for (let i = 0; i < n; i++) { let s = x[i]; for (let k = 0; k < i; k++) s -= L[i * n + k] * x[k]; x[i] = s / L[i * n + i] } for (let i = n - 1; i >= 0; i--) { let s = x[i]; for (let k = i + 1; k < n; k++) s -= L[k * n + i] * x[k]; x[i] = s / L[i * n + i] } return x }

// LP 内点法：min c·z s.t. A z ≤ b（A 稠密 rows×n 行主序）。Mehrotra 预估-校正。
function lpSolve(A, b, c, n, rows, z0, s0) {
  const z = Float64Array.from(z0), s = Float64Array.from(s0), y = new Float64Array(rows).fill(1)
  const Az = new Float64Array(rows), rp = new Float64Array(rows), rd = new Float64Array(n), rc = new Float64Array(rows)
  const Nm = new Float64Array(n * n), rhs = new Float64Array(n), tmp = new Float64Array(rows)
  const dz = new Float64Array(n), ds = new Float64Array(rows), dy = new Float64Array(rows)
  const dzA = new Float64Array(n), dsA = new Float64Array(rows), dyA = new Float64Array(rows)
  let it = 0, ok = false
  const mulA = (v, out) => { for (let i = 0; i < rows; i++) { let t = 0; const r = i * n; for (let j = 0; j < n; j++) t += A[r + j] * v[j]; out[i] = t } }
  const mulAT = (v, out) => { out.fill(0); for (let i = 0; i < rows; i++) { const vi = v[i]; if (vi === 0) continue; const r = i * n; for (let j = 0; j < n; j++) out[j] += A[r + j] * vi } }
  const solveNewton = (rcv, outZ, outS, outY, L) => {
    for (let i = 0; i < rows; i++) tmp[i] = (rcv[i] - y[i] * rp[i]) / s[i]
    mulAT(tmp, rhs)
    for (let j = 0; j < n; j++) rhs[j] = rd[j] - rhs[j]
    outZ.set(cholSolve(L, rhs, n))
    mulA(outZ, tmp)
    for (let i = 0; i < rows; i++) { outS[i] = rp[i] - tmp[i]; outY[i] = (rcv[i] - y[i] * outS[i]) / s[i] }
  }
  const stepMax = (v, dv) => { let a = 1; for (let i = 0; i < v.length; i++) if (dv[i] < 0) a = Math.min(a, -v[i] / dv[i]); return a }
  for (it = 0; it < 60; it++) {
    mulA(z, Az)
    let pn = 0, mu = 0
    for (let i = 0; i < rows; i++) { rp[i] = b[i] - Az[i] - s[i]; pn = Math.max(pn, Math.abs(rp[i])); mu += y[i] * s[i] }
    mu /= rows
    mulAT(y, rd)
    let dn = 0
    for (let j = 0; j < n; j++) { rd[j] = -c[j] - rd[j]; dn = Math.max(dn, Math.abs(rd[j])) }   // ★ Aᵀy = −c
    let obj = 0; for (let j = 0; j < n; j++) obj += c[j] * z[j]
    if (mu < 1e-9 * (1 + Math.abs(obj)) && pn < 1e-8 && dn < 1e-8) { ok = true; break }
    Nm.fill(0)
    for (let i = 0; i < rows; i++) {
      const d = y[i] / s[i], r = i * n
      for (let a = 0; a < n; a++) { const va = A[r + a] * d; if (va === 0) continue; for (let bq = 0; bq <= a; bq++) Nm[a * n + bq] += va * A[r + bq] }
    }
    for (let a = 0; a < n; a++) for (let bq = 0; bq < a; bq++) Nm[bq * n + a] = Nm[a * n + bq]
    let L = null
    for (let k = 0, reg = 1e-12; k < 8 && !L; k++, reg *= 100) { const C = Nm.slice(); for (let a = 0; a < n; a++) C[a * n + a] += reg * (1 + Math.abs(Nm[a * n + a])); if (cholFactor(C, n)) L = C }
    if (!L) break
    for (let i = 0; i < rows; i++) rc[i] = -y[i] * s[i]                       // 预估
    solveNewton(rc, dzA, dsA, dyA, L)
    const apA = stepMax(s, dsA), adA = stepMax(y, dyA)
    let muA = 0; for (let i = 0; i < rows; i++) muA += (y[i] + adA * dyA[i]) * (s[i] + apA * dsA[i]); muA /= rows
    const sig = Math.min(1, Math.pow(Math.max(muA / mu, 0), 3))
    for (let i = 0; i < rows; i++) rc[i] = sig * mu - y[i] * s[i] - dyA[i] * dsA[i]   // 校正
    solveNewton(rc, dz, ds, dy, L)
    const ap = Math.min(1, 0.995 * stepMax(s, ds)), ad = Math.min(1, 0.995 * stepMax(y, dy))
    for (let j = 0; j < n; j++) z[j] += ap * dz[j]
    for (let i = 0; i < rows; i++) { s[i] += ap * ds[i]; y[i] += ad * dy[i] }
  }
  return { z, iters: it, ok, y }
}

// 严格 minimax：SLP + 信赖域。G 为 M×N 实 beamlet 场（稠密示意），Q 为 N×N，T 为站点目标（此原型全 contour）。
function minimaxSLP({ G, Q, T, N, M, x0, maxIter = 60, tol = 0.01 }) {
  const n = 2 * N + 1, x = Float64Array.from(x0)
  const Er = new Float64Array(M), Ei = new Float64Array(M), r = new Float64Array(M), gP = new Float64Array(2 * N)
  const evalAt = (xx, outR) => {
    let P = 0; const Qx = new Float64Array(2 * N)
    for (let j = 0; j < N; j++) { let sr = 0, si = 0; for (let k = 0; k < N; k++) { const q = Q[j * N + k]; sr += q * xx[k]; si += q * xx[N + k] } Qx[j] = sr; Qx[N + j] = si; P += xx[j] * sr + xx[N + j] * si }
    for (let j = 0; j < 2 * N; j++) gP[j] = 2 * Qx[j] / P
    let mx = -Infinity
    for (let m = 0; m < M; m++) {
      let er = 0, ei = 0; const row = m * N
      for (let j = 0; j < N; j++) { const g = G[row + j]; er += g * xx[j]; ei += g * xx[N + j] }
      Er[m] = er; Ei[m] = ei
      const p2 = Math.max(er * er + ei * ei, 1e-30 * P)
      outR[m] = T[m] - 10 * Math.log10(p2 / P)
      if (outR[m] > mx) mx = outR[m]
    }
    return mx
  }
  const normalize = (xx) => { let P = 0; for (let j = 0; j < N; j++) for (let k = 0; k < N; k++) P += Q[j * N + k] * (xx[j] * xx[k] + xx[N + j] * xx[N + k]); const s = 1 / Math.sqrt(P); for (let j = 0; j < 2 * N; j++) xx[j] *= s }
  normalize(x)
  let Fk = evalAt(x, r)
  let xmax = 0; for (let j = 0; j < 2 * N; j++) xmax = Math.max(xmax, Math.abs(x[j]))
  let Delta = 0.5 * xmax
  const rows = M + 4 * N
  const A = new Float64Array(rows * n), b = new Float64Array(rows), c = new Float64Array(n); c[n - 1] = 1
  const rNew = new Float64Array(M), K = 10 / Math.LN10
  let it = 0, accepted = 0, lpIt = 0
  for (it = 0; it < maxIter; it++) {
    A.fill(0)
    for (let m = 0; m < M; m++) {                       // 行 m：∇r_m·h − t ≤ −r_m，∇r_m = −∇f_m
      const row = m * n, gr = m * N, p2 = Math.max(Er[m] * Er[m] + Ei[m] * Ei[m], 1e-300)
      for (let j = 0; j < N; j++) { const g = G[gr + j]; A[row + j] = -K * (2 * Er[m] * g / p2 - gP[j]); A[row + N + j] = -K * (2 * Ei[m] * g / p2 - gP[N + j]) }
      A[row + n - 1] = -1; b[m] = -r[m]
    }
    for (let j = 0; j < 2 * N; j++) { A[(M + j) * n + j] = 1; b[M + j] = Delta; A[(M + 2 * N + j) * n + j] = -1; b[M + 2 * N + j] = Delta }
    const z0 = new Float64Array(n); z0[n - 1] = Fk + 1                       // h=0, t=F+1 严格可行
    const s0 = new Float64Array(rows)
    for (let m = 0; m < M; m++) s0[m] = b[m] + z0[n - 1]
    for (let j = 0; j < 4 * N; j++) s0[M + j] = Delta
    const lp = lpSolve(A, b, c, n, rows, z0, s0); lpIt += lp.iters
    const pred = Fk - lp.z[n - 1]
    let hInf = 0; for (let j = 0; j < 2 * N; j++) hInf = Math.max(hInf, Math.abs(lp.z[j]))
    if (pred < tol) break
    const xn = Float64Array.from(x); for (let j = 0; j < 2 * N; j++) xn[j] += lp.z[j]
    const Fn = evalAt(xn, rNew), act = Fk - Fn, rho = act / pred
    if (act > 0) { x.set(xn); normalize(x); Fk = evalAt(x, r); accepted++ } else evalAt(x, r)
    if (rho < 0.25) Delta = Math.max(Delta * 0.25, 1e-12)
    else if (rho > 0.75 && hInf > 0.9 * Delta) Delta *= 2
    if (Delta < 1e-9) break
  }
  let active = 0; for (let m = 0; m < M; m++) if (r[m] > Fk - 0.02) active++
  return { x, F: Fk, iters: it, accepted, lpIt, active, r }
}

## 附录 B：SATSOFT 依据摘录

- §10.2（PDF p132–134）：「The optimizer uses a mini-max algorithm, an iterative procedure that minimizes the maximum error at each iteration」；「computes the gain at each synthesis station… finds the station with the minimum margin. Contour margin = actual − desired, sidelobe margin = desired − actual (in dB)… modifies the beam coefficients so the margin is increased at the worst case point… repeated until the amount of improvement at each iteration drops below a preset level, or the maximum number of iterations is exceeded」；「no guarantee… may well converge on a relative minimum」；「What is important is the relative weighting of points」；生成栅缺省全 Contour、目标 = 成分波束峰值 − 5 dB。
