**原则**：
- 权威数据只在主进程一份，各窗口持只读副本，写入一律走事务。
- 派生数据不进实体：星位、等值线、grdLive、搜索池、计算结果缓存都按「实体 id + 版本号」缓存。
- 过渡期**双写投影**：工程实体改动后，投影回旧的 localStorage 键 / userData 文件形状，没迁移的窗口照常能读。迁一个窗口，删一处投影。

## 4 分块设计

### 4.1 F-01 统一对象模型（`packages/core/scene/`）

**类型注册表** `registry.mjs`。每种实体登记 `{ type, version, props, relations, labels, icon? }`。每个属性带：
- 类型（number / string / enum / bool / ref / array / object）
- SI 单位与量纲
- 范围：直接收编 `src/shared/lbValidate.js` 里已有的约 152 个字段范围，不重写
- 缺省值
- 双语标签与悬停口径（title）
- 是否参与「输入指纹」

同一份注册表派生出：
- JSON Schema：校验工程文件；
- d.ts 与 Python 存根：给 F-07；
- 表单渲染所需元数据：可选，供以后的通用属性检查器。

**首批实体类型**：

| 类型 | 主要属性 | 现在散在哪 |
|---|---|---|
| satellite | 轨道来源（catalog NORAD / omm / ephem / design / fixedGeo）、轨位、质量与面质比（可选）、版本 / 型号、显示样式 | 星座集、自定义卫星、天线树卫星、四个链路预算卫星库 |
| constellation | 设计（Walker / 九类向导参数）、场景历元（钉死）、成员规则（面号 + 槽号） | `constellation3d/customConsts` |
| satSet / satGroup | 成员（实体 id 或编目规则）、颜色 | `constellation3d/satSets` / `satGroups` |
| antenna | 归属卫星、方向图来源（GRD 文件资产 / 解析模型 / 合成设计）、指向律、名称 | 天线树（5 份） |
| transponder | 归属卫星、频段、SFD / IBO / OBO、转发器特性（预留非线性曲线） | 链路预算卫星库、频率计划 |
| carrier | 调制、MODCOD、符号率、滚降 | 载波库 |
| earthStation | 站址、天线、射频参数（实例属性，口径对号机制退役）、约束（预留 horizonMask / azElMask） | 标记站、链路预算地球站库、性能表 / 气象 / 日凌 / 雨衰 / C/I / 模型窗各存一份拷贝 |
| point / areaTarget | 位置 / 多边形（经纬线性边，跨日界线与修复轮同口径） | `globe3d/markers` 点、`globe3d/polygons` |
| platform | 航迹（时刻钉点）、模型、姿态参数（预留） | `globe3d/markers` 航迹 |
| link | 端点（实体 id）、跳、体制 | 图上链路 `globe3d/markers`、链路预算行 |
| coverageDef / analysis / analysisPeriod / eventSet / reportStyle / study | 见各块 | 新增 |

**身份**：
- 实体 id 用 UUIDv7（时间有序、可排序）。
- NORAD、COSPAR、ITU 名、GRD folder、显示名都降为属性。
- 星座成员身份 = 星座 id + 面号 + 槽号，不再占用 900000 以上的合成号段（合成号只作兼容别名保留）。

**别名表** `aliases.mjs`：一次性迁移生成，把旧 6 套键全部映射到新 id，此后只读。
- 旧键：`n:<NORAD>`、`norad:<n>`、`grd:<folder>`、`lb:<ns>:<id>`、`es1 / bb1 / sat1`、`st: / pt: / tr:`、`folder|name`。
- 提供 `resolveLegacy(key) → id` 与 `legacyKeysOf(id)`。

**关系与引用完整性**：
- 父子关系：卫星 ▸ 天线 ▸ 发射机 / 接收机；地球站同理。
- 类型化引用：链路端点、载波 → MODCOD 等。
- 删除时按关系类型三选一：阻止 / 级联 / 置为无效，并报出真实引用数。真实引用数按「实际解析到哪份条目」算，取代现在只认字面 id 的 `refCount`；记忆里提过的坑：行里存空串等于用库里第一份。

**模板与实例**：
- 资源库里的站型、载波 / MODCOD、载荷是模板；工程里是实例加改写层，只存差异（与 MODCOD「内置 + 改写层」同一做法）。
- 「一只转发器 = 一个转发器实体」，对上容量汇总与高级计算「一组 = 一只转发器」的口径。

**验收**：
- 注册表单测：每个属性范围与 `lbValidate` 逐项一致。
- 别名表往返：旧键 → id → 旧键，逐个还原。
- 关系完整性随机测试。

### 4.2 G-09 工作区存储 + 主进程 `sceneStore`

**存储形态**（推荐，待拍板 §8 #3）：工程即目录。
- `manifest.json`
- `objects/<type>/<id>.json`：一个实体一个文件，键序稳定、LF、两格缩进
- `journal.jsonl`：追加式事务日志，崩溃恢复与撤销都用它
- `assets/<sha256>`：GRD、星历采样等大件，内容寻址

规则：
- 写入沿用 `jsonStore.js` 的原子写语义（tmp → rename，留 .bak，读坏拒写）。
- 定期把 journal 压实进 objects。
- 不引入原生模块。备选是 SQLite：Electron 31 自带 Node 20，没有 `node:sqlite`；better-sqlite3 要原生重编。待 Electron 升级后再评估。

**sceneStore API**（主进程）：
- 读：`open(dir)`、`snapshot()`、`get(id)`、`query(type, filter)`；
- 写：`tx(ops, { origin, label })`，ops 是对象级 JSON Patch（RFC 6902）。先经 schema 校验，再写 journal、改内存文档，然后广播补丁；
- 订阅：`subscribe(webContentsId)`。

**IPC**：`project:snapshot`、`project:tx`、`project:subscribe`，主进程推送 `project:patch`。补丁带发起窗口 id 与事务序号，各窗口按序号应用，丢号就整份重取快照。

**渲染端** `src/shared/useProject.js`：
- 提供只读响应式副本（`shallowRef` + 按实体 id 的 Map，别对整份文档做深监听）、选择器 `useEntity(id)` / `useEntities(type, filter)`、写入 `tx(ops)`。
- 写入前现造纯数据（IPC 规矩）。

**过渡期双写投影** `electron/services/legacyProjection.js`：每次事务后，把受影响的实体投影回旧形状：
- `globe3d/settings` 的相关子键、`globe3d/grdSats`、`lb/grdSats`、`ci/grdSats`、`constellation3d/*`、`globe3d/markers`、`globe3d/polygons`、`library.json` 等。
- localStorage 在渲染端：由主窗收到投影指令后写入，并就地补发一次 `storage` 事件（记忆坑：`storage` 事件只在别的窗口触发）。

**首启迁移**「旧工作区 → 工程 v1」：
- 渲染端（主窗）把全部旧 localStorage 键与主进程 userData 文件交给迁移器，生成缺省工程「我的工作区」。
- `restoreSettings` 里那十几处就地迁移挪进迁移器第 0 步。
- 旧数据原样保留，直到用户确认，不删。

**备份与位置**：
- 工程目录可选位置；缓存类数据移到 `%LOCALAPPDATA%`。
- 每日轮转备份：7 日 + 4 周。

### 4.4 F-09 计算作业层（`electron/services/jobs/`）

- **作业**：`{ id, kind, spec（纯数据）, priority, progress, cancel（SharedArrayBuffer 标志）, result }`。
- **worker 池**：worker_threads，线程数 = 核数 − 1。每个线程预载 core，ITU 全精度数据以只读共享缓冲传入。起线程方式参照 `pfdMaskWorker.js` 从 asar 起线程的先例。
- **确定性分片**：蒙特卡洛按样本块分、事件按时间段分、覆盖按网格行分。子种子用 splitmix 从主种子派生，并写进结果。
- **渲染端** `useJob`：进度、取消、「输入已变」。大块结果走 transferable 或落文件。
- **首批迁移**：`link:sweep2D`、`link:slaScanBatch`、NGSO 批量、`rain:sweep`、日凌批量、C/I NGSO 长扫描、可见性 / 覆盖计算（现在在渲染主线程分批跑）。
- **验收**：单线程与池化结果逐位一致；蒙特卡洛 8 核加速比 ≥ 5。

### 4.7 F-03 事务撤销

- 每次 `tx` 自动生成正向 / 逆向补丁。一个用户动作 = 一个事务，例如：一次拖动、一次描绘、导入一条链路造出 N 行、删一颗星连带的引用。
- 撤销前核对目标路径的当前值是否等于记录的后像；不等就拒绝整个事务，并指出冲突对象，不做部分回放。
- 按来源窗口分栈：Ctrl+Z 撤本窗口最近一次。另设「历史记录」面板看全工程，可跳转，可选择性撤销互不冲突的事务。
- 沿用现有 700 ms 合并规则；撤销时恢复选择状态。
- 外部副作用（写外部文件、发小程序、GRD 进回收站）在事务里只登记、不回放。
- 逐个并入现有局部栈：`sceneUndo.js` 三个域 → 频率计划 → 链路表 → 波束组 → 装配 → C/I。每并一个都要回归。
- **验收**：
  - 随机命令序列属性测试：全部撤销后等于初态，全部重做后等于终态；
  - 跨窗口夹具：主窗删站 → 链路预算行失效 → 撤销 → 两边都恢复。

### 4.8 F-07 自动化

- **平台 API**：F-01 对象模型的门面，由注册表生成。按域分：
  - `project`、`objects`、`time / clock`；
  - `analyses.run`（带进度与取消，走作业层）；
  - `providers`、`events`、`reports`、`export`；
  - `ui.exec`：执行 `commands.js` 里的命令 id。
  
  语义化版本，设弃用期；d.ts / Python 存根 / MATLAB 帮助都由生成器产出。
- **四个入口**：
  1. **脚本控制台独立窗口**：复用 Monaco、d.ts 与沙箱 Worker。在「只回文件」的基础上加能力受限的 RPC：Worker 持一个 MessagePort，主进程按白名单清洗参数（照 `sceneCmd.js`）。文件读写只允许用户授权过的目录；长任务交作业层，不受现有 6 s 超时限制。
  2. **无界面命令行**：`satsim --headless --project x.satproj --run job.js|job.json --out dir`，有退出码，日志为 JSON 行。纯计算走 Node + core；出图 / 视频 / PDF 走 Electron 隐藏窗口。单实例锁与 updater 要识别 headless 模式（`electron/main.js` 约 33–47 行）。
  3. **本地自动化服务**（缺省关闭，在设置里开）：JSON-RPC 2.0，走命名管道 `\\.\pipe\satsim-<用户>`，或回环 HTTP 加令牌文件。拒收带 `Origin` 的浏览器请求以防 CSRF。可订阅事件：时钟拍、计算完成。
  4. **客户端**：Python 包（纯 Python，结果转 numpy）；MATLAB 类（webwrite 或 .NET NamedPipeClientStream）。
- **引擎下沉**：GRD 覆盖采样（`src/viz/grd/*`）、可见性与星座、对星计算、渲染端那一份 SGP4，迁进 core（ESM，与 G-10「core 改 ESM」同做）。不迁的话，无界面运行不完整。
- **授权与安全**：所有入口照走 `gate()` 与激活书校验；脚本读不到凭证；审计日志写 main.log。
- **验收**：
  - API 契约测试：存根与实现对拍；
  - 同一工程，界面出的报告与无界面出的报告逐字节一致，时间戳除外；
  - Python 跑蒙特卡洛与界面参数研究结果逐位一致。

### 4.9 F-08 参数研究（`packages/core/study/`）

- **因子**：任意对象属性路径（F-01 寻址）。取值可以是范围、离散集或分布（均匀 / 正态 / 截断正态 / 三角 / 对数正态 / 经验 CDF），相关性用 Iman–Conover。
- **输出**：F-06 的元素或分析结果字段，可加约束与目标。
- **采样**：全因子、拉丁超立方（maximin）、Sobol 序列（Joe–Kuo 方向数）、蒙特卡洛（种子写进结果）。
- **优化**：Nelder–Mead、CMA-ES、NSGA-II（多目标 Pareto），离散变量用混合编码。
- **敏感性**：Morris 初筛 + Sobol 一阶 / 总效应（Saltelli 估计）。置信区间用块 bootstrap，从 ciNgso 抽到 `study/stats.mjs`，算法不改。
- **收编现有能力**，逐位回归：一维 / 二维扫描是全因子的特例；SLA 九档是离散扫描；C/I 多历元是蒙特卡洛采样器。高级计算的平衡和计算方式求解保留闭式，不并入。
- **界面**：「参数研究」独立窗口。因子不对用户全开，用研究模板预置有工程含义的因子：选型、雨区不确定性、构型敏感性；完全任意的属性走 F-07 脚本。结果只出表里没有的东西：散点矩阵、Pareto 前沿、超越概率曲线。**不**回到链路预算可视化区加扫描图——那里的扫描 / 可行域已被用户删掉。
- **验收**：
  - Ishigami 与 Sobol-G 的解析 Sobol 指数落在置信区间内；
  - Rosenbrock、ZDT1–3 优化基准；
  - sweepLink 逐位回归；
  - 样本翻倍时，区间宽度按 1/√N 收缩。
