0. 总体
──────────────────────────────────────────────────────────────────────────────
· 纯 ASCII，CRLF 行尾。
· 【自描述】：每个字段前一行 "*说明文字"，值写在紧接的下一行（个别字段两行两值）。
· "*" 开头行与空行忽略（手册 §13.4 明说）。
· 识别签名：第一行为 "#CAL1"。
· 单波束格式。多波束 = 【每个波束一份完整表头 + 一份数据，顺序拼接】
  （手册："written sequentially... each beam preceded by its own header"）。
  实测 ① 11 段、② 94 段、③ 1 段。
· 【网格 = 源 .grd 的网格】：SATSOFT 不自选栅。样本 ③ 的 az/el 上下界与点数
  （-7.763838..2.666499 / 1.474457..9.231907 / 120×90）与源 XS/YS/XE/YE、NX/NY
  逐位相同 —— 顺带也证明 az 轴【不取反】。

──────────────────────────────────────────────────────────────────────────────
2. 数据段
──────────────────────────────────────────────────────────────────────────────
Naz×Nel 个 dB 值，【每行 4 个】（末行放余数：181²=32761=8190×4+1）。

索引（由字段 10/11/12 决定，三份样本均为 az 最快、两轴升序）：
    n = iel*Naz + iaz        iaz = n mod Naz,  iel = ⌊n / Naz⌋
    az = azmin + (azmax−azmin)·iaz/(Naz−1)
    el = elmin + (elmax−elmin)·iel/(Nel−1)

★ -200 = 无数据哨兵（见 §5）。
值的语义随源：源是 EIRP 网格则为 dBW；手册称其为 directivity dB。

──────────────────────────────────────────────────────────────────────────────
3. ★ 坐标换算做不做，取决于源的 igrid
──────────────────────────────────────────────────────────────────────────────
ACP4 的 az/el = SATSOFT 坐标系 3（azimuth over elevation 转台，y 极轴）。
    GRASP igrid=4  ＝ SATSOFT kgrid3 ＝ ACP4 自己的栅  → 【不重采样，节点值直接搬】
    GRASP igrid=6  ＝ SATSOFT kgrid4（x 极轴，另一种直角 az/el）→ 【重采样 + 换算】

由 ACP4 的 (az_a, el_a) 反求 igrid=6 源的 (Az, El)：
    rx = −sin(az_a)·cos(el_a)
    ry =  sin(el_a)
    rz =  cos(az_a)·cos(el_a)
    El  = atan2(ry, rz)
    Az  = atan2(−rx, hypot(ry, rz))
【无镜像】：+az(ACP4) 与 +Az(GRASP) 同向，都指东。

实测（峰下 0~6 dB 区间的 RMS，dB）：
    样本            源 igrid   原样搬      做换算
    ① 300_X02G        6       0.07133   → 0.00238      换算成立
    ③ 赋形反射面      6       0.08269   → 0.00068      换算成立
    ② EIRP_OK1        4       0.00003     （不需要，见下）逐点全等
另：az 镜像假设在 ① 上全场 RMS 达 9.2 dB，直接排除。

哨兵个数也印证了这条：② 不换算 → 哨兵 0 个；① 换算 → 399 个；③ 换算 → 120 个。

    set   P1峰     P2峰     RSS峰     ACP4 表头 peak

──────────────────────────────────────────────────────────────────────────────
5. 插值域：线性功率（绝不是 dB 域）
──────────────────────────────────────────────────────────────────────────────
样本 ① 按电平分层的残差 RMS（dB）：

    插值域              峰下0~6   峰下6~20   峰下20~40   峰下>40
    dB 域 bicubic        0.0034    0.0320     15.8529     31.8840   ← 零点处爆炸，排除
    线性功率 bicubic     0.0024    0.0167      0.1887      3.4600
    线性功率 bilinear    0.0064    0.0852      0.3727      0.7781
    复场 bicubic         0.0038    0.0417      0.6449      2.3908

主瓣区四者都 ≤0.006 dB；深零点区的残差是【插值核不同】所致——手册 §12.2.8 说
SATSOFT 用 bicubic Lagrangian，上表用的是 Keys(a=−0.5)。工程实现取线性功率域
bicubic 即可（主瓣 0.002 dB、−20 dB 以内 0.19 dB）。

──────────────────────────────────────────────────────────────────────────────
6. -200 哨兵的判据
──────────────────────────────────────────────────────────────────────────────
规则 = 【换算后的 (Az,El) 落到源网格窗口之外】。不做换算的源（igrid=4）无哨兵。

样本 ①：398 个哨兵中 375 个满足该条；反向只有 1 个有值点越界（越界 0.11°）。
用「越界 > 0 判无数据」拟合，32761 点里仅 24 点判错（99.93%）。
剩下 23 个"落在窗内却仍是 -200"的点全部贴在边界（|az| ≥ 6.6，多为 8.6~9.0）
或源场为零处——即插值模板取不满 / 零场。

旁证（很能说明换算确实做了）：el = −9.0° 整行 180 个哨兵、el = +9.0° 整行 179 个，
只有 az≈0 的一两点幸存。因为换算后 El = atan2(sin(±9), cos(az)·cos(±9))，
只有 az=0 时才恰好 = ±9°，其余一律越界。

──────────────────────────────────────────────────────────────────────────────
7. ★★ SATSOFT 读 EIRP_OK1.grd 时的 off-by-one（实测坐实，勿照抄）
──────────────────────────────────────────────────────────────────────────────
样本 ② 的 beam1 数据 = 源 set1 的【第 1..32761 号点】（0 基），即整体前移一个记录：
把源的 0 号点丢了，末尾多读了一条。三条独立证据：

  (a) 首值：2.pat 头四个值 -10.6552 / 1.81956 / 11.3362 / 8.8142
      源 set1 的 0/1/2 号点 dB = -22.3154 / -10.6517 / 1.8196  → 错开一个点。
  (b) 跨行绕回：2.pat 的 179 号值 = -61.3383 = 源 180 号点（az=+9,el=-9 角），
      2.pat 的 180 号值 = -15.773 = 源 181 号点（az=-9,el=-8.9）——按【线性下标】
      整体 +1，不是逐行平移，说明是读流层面的错位而非坐标变换。
  (c) 末值：2.pat beam1 最后一个值 = 25.1055，而 10·log10(9²×4) = 25.1055 ——
      正是【下一个 set 的边界行 "-9 -9 9 9" 被当成一条场记录读了】。
      源文件核对：set1 数据占第 100~32860 行（正好 32761 条），第 32861 行即
      set2 的边界行。故 SATSOFT 确实越界读了一条。

对齐搜索（主瓣点，az/el 各 ±4 格 × 镜像 × 转置 × 前 3 个 set 全搜）：
    最佳 = set1 / az 平移 +1 格 / 无镜像 / 无转置 → RMS 0.00003 dB
    不平移 → RMS 3.68 dB
即除这一格错位外，② 是【逐点全等的拷贝】（无插值）。

范围：只影响 ② 的 beam1（beam2..94 的末值都是正常场值，非 25.1055）；
      样本 ① ③ 完全没有这个现象（末值都是正常的 -200 哨兵）。

可能的触发条件（三份样本里 ② 独有的）：ktype=2（① ③ 为 1）、
【文件没有标题行，第一条记录就是 "++++"】（① ③ 都有标题行）、igrid=4、icomp=2。
单凭一份样本无法定因，不臆测。

【结论与用法】
  · 我方实现 ACP4 导入时，第 k 个值就是第 k 个格点，【不要复刻这个错位】。
  · 拿 SATSOFT 做交叉校验时要留意：对 EIRP_OK1.grd 这类文件，SATSOFT 眼里的
    beam1 比文件本身【向 az 负方向偏了一格（本例 0.1°，GEO 地面约 75 km）】。
    按文件自身的头部定义，本平台的读法是对的。
  · 待确认：这个错位是在 SATSOFT 的【读取器】还是仅在【ACP4 导出器】。
    在 SATSOFT 里看 beam1 的峰值 az —— 读到 -1.7 说明是读取器，-1.6 说明只是导出器。
