## 1 目标（三条硬口径）

| # | 动作 | 口径 |
|---|---|---|
| 1 | **导出 = 全量** | 不让用户勾选。把本机全部「用户工作数据」打成一个 `.satproj`，包括 GRD 原文、星历原文、用户模型、历史版本 |
| 2 | **双击 .satproj = 原样还原** | 还原后的工作区与导出时完全一致：对象、引用、GRD、可见性、场景历元与时刻、计算配置都一致，计算结果逐位一致。判定方法：导出 → 双击还原 → 再导出，两个包除 `manifest.createdAt` 外逐字节一致 |

  remap(item, table) { ... },    // 改 id / 改名 / 改文件名时，按重写表改写本模块内部的所有引用
  apply(items, mode) { ... },    // mode: 'replace' | 'merge'

## 4 包格式

### 4.1 布局

`.satproj` 是 zip。布局是「镜像 + 索引」：还原时靠镜像保证逐字节一致，选择性导入时靠索引出预览，不用解开大件。

```
manifest.json          格式标识、formatVersion、软件版本、createdAt、场景历元、各模块计数与字节数、每个条目的 {path, sha256, size}
index.json             §3 items() 的输出：模块 → 条目树 → 依赖边 → 内容哈希（导入预览只读它）
files/<userData 相对路径>   A 类文件原样
ls/<key>.json          A 类 localStorage 键（拆过的混合键只存取出的段）
```

### 4.2 确定性（往返逐字节一致的前提）

- 条目按路径字典序排列，mtime 固定写 1980-01-01。
- 压缩档固定；`.grd` 文本压缩，已压缩的格式（`.glb`、PNG）用 STORE。
- JSON 用规范序列化：键序固定、数字格式固定、换行统一 LF。

### 4.3 大件

- 用仓库已有的 fflate 做流式压缩，不在渲染端物化整份文件。记忆 `grd-export-oom-whitescreen` 记着 `Uint8Array.from` 逐字符物化导致白屏。
- 打包和解包都在主进程或 Worker 里做，渲染端只收进度。
- **Zip64**：包超过 4 GB 或条目超过 65535 时，必须能写能读。P1 先确认 fflate 支持；不支持就换成熟库（yazl / yauzl）。不允许静默截断。

### 4.4 完整性与迁移

- **完整性**：解包时逐条校验 sha256，任何一条对不上就整包拒收，报一句「场景包已损坏。」。
- **迁移**：纯函数链 `packages/core/satproj/migrations/vN→N+1`，每一步配夹具。未知字段原样保留并写回。

## 5 三条路径

### 5.1 导出（全量）

- **入口**：文件管理新增页签「场景包」，放在最右，原有五个页签不动。另在标题栏搜索登记「导出场景包」。
- **流程**：点「导出场景包…」→ 系统保存对话框，缺省文件名 `场景_YYYYMMDD-HHmm.satproj` → 进度条（字节进度，可取消）→ 读数行「已导出 · 1.24 GB · 386 项 · 12.4 s」，旁边一个「在文件夹中显示」。
- **导出前快照**：导出时各窗口可能还在编辑，必须取一致快照。
  - 先让所有窗口把防抖中的自动保存立即落盘（广播 flush，等全部 ack，超时报错）；
  - 再读 localStorage（主窗口走 IPC 汇总）；
  - 读取期间加读锁，拦住写入。

### 5.2 双击还原（整体替换）

**系统接入**

- electron-builder 配 `fileAssociations: [{ ext: 'satproj', name: '卫星仿真平台场景包', description: …, icon: 'build/icon.ico', role: 'Editor' }]`，`perMachine:false`，注册在 HKCU。
- `patch-nsis-template.mjs` 打的补丁必须与关联注册共存。卸载时清掉关联。静默自动更新之后关联还在。
- 改动后跑一次 `npm run dist` 的安装段，在干净的虚拟机或用户机上验证图标显示与双击行为。
- 冷启动从 `process.argv` 取路径。软件已在运行时，从 `second-instance` 的 argv 取路径（现在 main.js:36 不读 argv）。路径进队列，等主窗口就绪后再处理。拖一个 `.satproj` 到主窗口，走 §5.3 选择性导入，不走替换。

**流程**

1. 校验包：格式、版本、sha256。
2. 判断本机工作区是否为空（没有 A 类数据，或者与最近一份自动备份逐哈希相同）：
   - **空** → 跳过确认，直接还原。新装机器双击即用。
   - **非空** → 弹确认框（§6.3）。
3. **自动备份当前工作区。** 备份本身就是一个全量 `.satproj`，存到 `UD/backups/`，原因记为「双击打开前」。
4. 关掉除主窗口外的所有窗口，主窗口进入遮罩态。
5. 主进程原子替换：
   - 文件先解到 `UD/.satproj-staging/`，再逐目录换名替换；
   - 任何一步失败，就从备份滚回，并报一句错。
6. localStorage 注入：先清掉注册表里登记的 A 类键（B / C 类键不碰），再写入包里的值，混合键按 §2 合并。主进程不能直接写 localStorage，由主窗口经 IPC 写。
7. 主窗口重载，按包里的视图状态恢复机位和时刻。之前开着的计算窗口不自动重开。

**验收**：§7 的 R1–R3。

### 5.3 软件内选择性导入（按模块）

- **入口**：「场景包」页签里点「导入场景包…」；或者把文件拖到主窗口。
- **交互**：见 §6。

**导入引擎**

- **身份判定**，每个条目按顺序判断：
  1. 稳定 id 相同 + 内容哈希相同 → **相同**：默认跳过，置灰。
  2. 稳定 id 相同 + 内容不同 → **冲突**。
  3. id 不同但同模块、同父级下同名 → **同名**。
  4. 其余 → **新增**。
- **临时身份**：身份修复轮落地前，天线用 `folder|name`、卫星用 `folder`、配置用 `cfgId` 充当 id，并在方案里标明这是临时口径。
- **依赖闭包**：勾选一个条目，自动带入它引用的条目，复用 lbShare v3 的闭包算法。依赖关系包括：
  - 链路预算配置 → 卫星 / 天线 / GRD / 资源库条目；
  - 频率计划 → 卫星节点；
  - 波束合成 ↔ 频率计划；
  - 卫星集 → 星座 / 星历组 / 卫星组；
  - 模型绑定 → 模型。

  本机已有「相同」的依赖不重复带入，引用直接指向本机那份。
- **重写表**：每次导入生成一张表 `{旧 id → 新 id, 旧文件名 → 新文件名, 旧 NORAD → 新 NORAD}`，所有被选条目和被带入的依赖都经各模块的 `remap()` 统一改写。
  - 触发改写的情况：「保留两者」导致重发 id；GRD 文件名撞车（现有 `_n` 后缀规则）；合成 NORAD 号撞车（自定义星座 900000 段、星历组 800000 段，重新发号）。
  - 不许各模块各自补丁。
- **事务**：导入前先做自动备份，原因记为「导入前」。全部写入成功后再广播刷新；任何一步失败就整体滚回。不允许导一半。
- **立即可见**：写完向各窗口广播 `satproj:applied {modules}`，各窗口重读对应存储，不用重启。

### 6.3 交互规则

- **左侧树**
  - 第一层是 §3 的模块，第二层以下保留原有层级（卫星 › 天线；配置树的文件夹 › 配置）。
  - 复选框三态。模块行的读数是「条目数 · 冲突数⚠」。
  - 虚拟滚动，复用 SatList 的实现。上千条目也不卡。
- **默认勾选**：全部不勾（§8 #4）。顶部筛选框右侧放「全选」。
- **状态签**：新增 / 冲突 / 同名 / 相同 / 依赖。
  - 「相同」置灰，默认不勾；勾上也只是刷新引用，不改数据。
  - 「依赖」行前面是链接图标，复选框锁定为勾选。悬停 `title` 显示「被 X、Y 引用」。取消勾选所有引用它的条目后，依赖行自动消失。
  - 用户想单独导入一个依赖条目，就在它所在的模块里直接勾它，它就从「依赖」变成普通条目。
- **右侧详情**（聚焦行）
  - 冲突条目：左右对照字段差异，只列有差别的字段。GRD 这类大件只比较哈希、尺寸、修改时间，不展开内容。
  - 单选「保留两者 / 覆盖本机 / 跳过」。
  - 保留两者时，导入那份命名为「原名 (2)」。按现有资源库的自动命名规则（`lb-library-auto-naming`）处理：改过名的不动。
  - 非冲突条目只显示基本读数（类型、大小、引用关系）。
- **顶栏「冲突处理」下拉**：设定全部冲突的默认处理方式。逐项改过的条目保留逐项设置；改下拉时，带下划线标出哪些条目被逐项改过。
- **底栏读数**随勾选实时更新。没勾任何东西时，「导入」按钮禁用。
- **导入中**：对话框变为进度态（字节进度 + 当前模块），可以取消，取消即滚回。
- **导入后**：对话框收成一行结果「已导入 23 项 · 依赖 6 · 覆盖 1 · 4.1 s」，旁边是「撤销本次导入」和「关闭」。
  - 「撤销」= 从这次导入前的自动备份做整体还原，并且只还原这次涉及的模块。
  - 关闭后还可以在「场景包」页签的备份列表里撤销。
- **双击还原的确认框**：
  - 文件名一行；本机工作区与包内容各一行计数读数。
  - 三个按钮：「替换当前工作区」（主按钮）、「选择性导入…」（转到 §6.2）、「取消」。
  - 不写解释文字。悬停 `title` 写「替换前自动备份」。
