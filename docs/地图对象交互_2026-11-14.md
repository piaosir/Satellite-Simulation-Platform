# 地图对象交互

地图上的单击选中对象；对象右键菜单在名称下方的首项统一提供“对象设置…”，替换原先靠后的“在列表中定位”。二维和三维共用同一套设置入口，打开后选中并滚动到具体对象，而非仅切换面板。

| 对象 | “对象设置…”去向 |
| --- | --- |
| 点标记、地球站、航迹（载具、航点、航迹线） | 地图标记面板，选中对应对象，滚到属性检查器 |
| Polygon | Polygon 面板，展开列表，滚到并高亮该对象的设置卡片 |
| 覆盖库波束（GXT、KML、JSON 等） | 覆盖图面板，清除该批次的搜索条件，定位并高亮具体波束；沿用所属批次的样式设置 |
| 天线覆盖（GRD、解析方向图） | 对应的覆盖分析面板，设为当前编辑天线，展开天线设置 |
| 图上链路 | 链路面板，选中对应链路，展开并滚到链路详情 |
| 天线树虚拟卫星 | 已有卫星设置窗 |
| 自定义卫星或星座中的卫星 | 所属自定义卫星或星座的编辑向导 |
| 目录卫星 | 该卫星的信息栏 |

地图标记对象树的右键菜单同样提供“对象设置…”。树中的双击和 Enter 保留原有地图定位操作。

二维地图的双击恢复全图保持原样，包括在对象上双击时；工具态下仍优先处理工具操作。设置入口不占用双击。

## 悬停标签与隐藏

设置 → 交互设置 → 对象悬停标签：默认“一直显示”，可改为“不显示”或“限时显示”。限时模式允许输入秒数（支持小数，最少 0.1 秒），从进入对象开始计时，静止也会到时消失。同一对象内移动不续期；移开再进入、换到其他对象后重新计时。设置自动保存，关闭标签不会取消对象的手形反馈。

所有已识别对象的右键菜单在“对象设置…”下方统一提供一项“隐藏”，点击一次生效。标记、地球站、航迹、Polygon、链路保留原数据；覆盖库波束取消该束显示勾选，天线覆盖取消该天线显示勾选。卫星按身份在全部显示来源中隐藏，并移出聚焦，目录和星座成员不变；状态栏“重新显示”和地图右键菜单“显示隐藏的卫星”可恢复。其他对象可在原列表重新打开显示开关。

## 命中与手势

- 卫星沿用既有点选优先级；非卫星对象依次识别地球站、点标记、载具、航迹线、Polygon、覆盖图。
- 覆盖图只拾取当前渲染层。线条和中心优先于填色，重叠线取最近者，重叠填色取上层；未填色的轮廓内部、填色洞、透明图形与地球背面不拦截点击。
- 覆盖图按具体波束保存身份，允许名称包含分隔符。设置跳转不切换显示勾选，也不主动转动或缩放镜头。
- 绘制、放置等工具态的右键继续执行原有的加点、放置操作；不会误弹对象菜单。
- 对象删除后不再跳转；加载覆盖数据期间改选其他对象或切走侧栏，旧设置跳转作废。
