## 0 结论

1. **能做，零件大多已在。** 星历链路（17 组 GP + SATCAT + 四级链路 + 十余种格式导入导出 + 运营方星历叠加）、SGP4 与插值星历、Walker / 九类轨道向导、卫星集与 SATCAT 筛选、可见性 Access / Coverage、NGSO / 再生 / 端到端链路预算、MODCOD 与 ACM、NGSO 时变 C/I、PFD 掩模、频率计划、容量与 SLA、日凌、F10.7、全局时钟、交付级 Word / Excel 都现成。它们现在是**并列的工具**，缺一根按「一个星座」把它们串起来的脊梁：星座工程对象 + 根数历史 + 状态机，外加交会、寿命、调度三个新引擎。
2. **Starlink 管星座是八条线**（§1）：部署、构型保持与重构、碰撞规避、寿命与离轨、空间天气、网络运营、频谱合规、运营自动化。前五条管「星」，后三条管「网」与「规」。**平台的护城河——链路预算 + MODCOD + C/I + PFD 掩模 + 频率计划——正好在后三条上**，而 STK / FreeFlyer / GMV 一类轨道工具都没把这几样按星座串起来（§1.5）。
3. **设计**（§3）：新增「星座运管」——独立窗口十页（总览 / 构型 / 台账 / 部署 / 交会 / 环境 / 地面 / 网络 / 合规 / 事件）+ 主窗口一个活动栏视图「运管」（按状态 / 壳 / 面 / 槽位偏差着色、幽灵槽位、交会连线、蜂窝热图）+ 信息栏一节。状态机对齐 McDowell 公开分类，交会口径对齐 NASA 手册 Rev 2（2026-08），合规对齐 ITU Res.35 / Res.8 与 FCC 半年报六项。
4. **五条链把现有模块接起来**（§5）：构型 → 部署 → 保持；编目 → 交会 → 规避；空间天气 → 寿命 → 处置；地面段 → 链路 → 容量 → SLA；申报 → 掩模 → 里程碑 → 报告。八处「写好了却没接上」的孤岛（Art.22 限值表、链路行 → 载波、45 d 预报里的 Ap……）全部接进来（§2.2）。
5. **已在内置快照上实测**（§4）：11125 颗 Starlink 49 ms 拆出壳 / 面 / 状态；国网两壳、千帆滞留星、OneWeb 逐面高度错层都认得出；单历元状态与 CelesTrak 状态码、McDowell 分类对拍，偏差来源明确（漂移层被认成壳），正是历史库要补的那块；SGP4 0.77 µs/次，全星座 × 全编目 7 d 筛查在本机可压到 2 min 级。
6. **不做的**：EPFD 自校验（ITU 官方软件，7 月已定）、星间链路路由（08 月回退过，§9 问）、遥测与 FDIR、天基 SSA（没有数据）。
7. **建议起步**：S1 数据脊梁（约 6 千行）先做成单点原型——它单独就有价值（打开就能看 Starlink / 国网 / 千帆当前的构型与状态），也是其余六步的地基（§7.2）。待拍板 14 项见 §9。

### 1.2 八条管理线

**① 部署**
- 注入约 300 km 近圆（2026 年各批 242–329 km）；2022-02 磁暴前用过 210 km 近地点，那次 49 颗里 38 颗再入。
- 注入高度检测 21–50 d；不合格者在低轨被动再入（数天到数周）；早期离轨 181 颗 ≈ 1.4%。FCC 条件明文：不得直接部署到工作高度。
- 电推升轨中位 64 d、均值 78 d（2019–2025，多数 40–80 d）。
- **一箭多面靠 J2 差动进动**：经典做法是 60 颗分三组，20 颗直升，另两组在 350 km 分别停 35 d、70 d，到达相隔 20°、40° 的面。2025-08 至 2026-01 外部观测未检出任何换面机动——换面全靠升轨期间的差动进动。极轨与 70° 壳调面以「数月」计（Group 17-52 发射 75 d 后 24 颗里只有 2 颗入壳）。
- 发射后规避空窗：预申请临时编目号、部署后尽快上传自有星历与协方差（Space-Track 每 8 h 筛一轮）。

**② 构型保持与重构**
- 推进剂约够 5000 次机动，其中约 350 次规避（FCC 22-91 ¶72）；主推失效转冷气。
- 计入 ITU 里程碑的星须在名义高度 ±30 km、倾角 ±2° 内，连续超限 60 d 报 FCC。
- **2026「550 → 480 km」**：2026-01-01 宣布，约 4400 颗；理由是太阳极小期弹道衰减时间缩短 80% 以上（4 年多 → 数月）、500 km 以下碎片少、收拢轨道。快照实测 530–580 km 只剩 376 颗（70° 壳仍约 263 颗在 570–580 km），战役大体完成。
- VLEO 与 ISS 避让：340–360 km 最多 768 颗（与 NASA 协调值）；385–430 km 不做常态运行。
- 轨控是「每天规划数千次机动」，推力与阻力离散 / 连续组合，覆盖升轨、保持、降轨、壳层重排，方法为 MPC、凸优化、混合整数规划（2026 招聘信息）。
- 外部观测（arXiv 2603.25835，174 d）：45945 次轨道变动（约 264 次 / 天，74.6% 规避）；约 92% 的相位调整无可检出的高度变化；「双星 / 三星」近邻编组疑为在轨备份。

**③ 碰撞规避**
- 星上自主：输入星上 GPS 定轨 + 己方计划机动 + 19th SDS 与 LeoLabs 的 CDM；规避不得把其他会合抬过门限；缺省由 Starlink 让；对方可指令 Starlink 不机动；24/7 值班。对穿越壳层的卫星做时间域分工（远期对方机动、临近 TCA 由 SpaceX 机动）。
- **门限演变**：1e-5（2019–2023）→ 1e-6（2024-07）→ **3e-7 叠加脱靶距离判据**（2025-07 起；行业惯例 1e-4）。
- **半年规避次数**：2021H1 2219 → 2022-12~2023-05 25299 → 2023-12~2024-05 约 5 万 → 2024-12~2025-05 144404 → 2025-06~11 148696 → **2025-12~2026-05 207152**（Gen1 36、Gen2 46 次 / 星 / 年，约 1140 次 / 天）。他方为 Starlink 机动每期不到 20 次。
- 引发规避最多的次级目标里多个是中国在轨物体（2025-12~2026-05：TIANTIE KEJI 1809、鸿鹄二号 1740……）；SpaceX 称中俄运营者常不共享星历与联系方式。
- 「规避失效」按原因记账：CDM 迟到（跟踪差的碎片、磁暴期间）、非合作目标临近机动、第三方星历差、星上硬件降级、发射空窗、Space-Track 中断。
- **星历公开**：Space-Track + starlink.com 镜像，MEME 格式，60 s 步长、含 UVW 系 6×6 协方差、每天 3 批（实测清单 11152 个文件）；CelesTrak SupGP 即由它拟合。
- **Stargaze**（2026-01-30）：约 3 万个星敏感器兼作 SSA 传感器，日约 3000 万次过境探测，筛查从数小时缩到数分钟，对外免费。
- 事件：2021 年中国空间站两次避让；2025-12 Kinetica-1 载荷与 STARLINK-6079 最近约 200 m；2025-12-17 STARLINK-35956 与 2026-03-29 STARLINK-34343 内部能量异常产生碎片。

**④ 寿命与离轨**
- 设计寿命 5 年；按可靠性预测提前离轨（"bias towards de-orbiting and replacing"），再入落区选无人区。
- 开始离轨到再入中位：Gen1 76 d、Gen2 96 d（2025 下半年样本）；再入每天 1.2–2.6 颗；半年再入 472 / 218 / 260。
- 失效 object-years 台账：Gen2 累计 0.81，FCC 上限 100（约相当于 500 km 壳损失 20 颗以上），超限停止部署。FCC 5 年规则（§25.283(e)）对 2024-09-29 后发射的星适用。
- 生存分析：第 1395 d 生存率约 0.83，日失效概率约 1.3e-4，寿命约 4–6 年。

**⑤ 空间天气**
- 2024-05 Gannon 风暴：近半 LEO 活跃星同时机动，400 km 密度达 6 倍，ap 的 0–3 d 预报低估 100–300，7 d 会合筛查窗大量作废。
- 手段：侧身低阻安全模式、高阻时抬轨（申请过 +70 / −50 km 容差）、离轨前高阻模式、「ducking」（最小截面对准来袭目标，Pc 再降 4–10 倍）、轨控「solar storm resilience」专项。

**⑥ 网络运营**
- 全局控制器每 15 s 为每台终端分配卫星，全球同步在每分钟 :12 / :27 / :42 / :57 秒，另有星上 MAC 调度；89% 的切换落在重配时刻 ±1 s 内。
- 视场内 35–44 颗可用；终端最低仰角 25°（62°N 以北 5°，FCC 条件）。选星偏好（反向工程）：高仰角（45–90° 的星只占可用 30%、占被选 80%）、北向（GSO 排除区所致，82%）、光照、新批次。
- 小区：H3（dish API 返回 H3 cell ID；分辨率未公开，社区认为 res 5 = 252.9 km²、对边约 17 km，**未核实**）。波束：V2 下行 192 / 上行 144，V3 2048 / 2048。单星容量 V2 mini 约 96 Gbps、V3 1 Tbps；全网近 450 Tbps（2025-07）。Ku 下行 10.7–12.7 GHz 分 8 个 240 MHz OFDM 信道，最低两信道空置。
- 频率复用：Gen2 原许可同区同频只 1 个波束（Nco = 1）；2026-01 美国境内 EPFD 豁免放宽到 Nco ≤ 8，须保持 ≥ 4° GSO 排除区。
- 需求管理：售罄 / 候补 → 一次性拥塞附加费（$100 → $1500）、Residential Lite 高峰去优先级。
- 地面段：PoP 49 个（2025-12-29）；美国关口站 > 100 个站址、> 1500 副天线，全球估约 500 个（Quilty 2026，**未核实**）；典型每站 8 副 1.47 m Ka 天线，E 波段站 32 副。激光星间链路 > 9000 终端、日 > 42 PB（2024），> 13000 条双向链路（2025），V3 每星 6 × 400 Gbps。

**⑦ 频谱合规**
- Art.22 EPFD 由 ITU 官方软件（EPFD-A / EPFD-T，基于 S.1503-2）验证，结果与输入公开；SpaceX 靠 GSO 弧规避 + 降 EIRP 满足。
- FCC 26-26（2026-04-30）改美国境内 NGSO–GSO 判据：ACM 链路时间加权吞吐下降 ≤ 3%、不可用度增量 ≤ 0.1%、非 ACM 80% 时间 I/N ≤ −10.5 dB；最小规避角 3°（= 6° 排除区，规避角取排除区全宽的一半）。
- NGSO–NGSO：47 CFR 25.261，同轮 ΔT/T > 6% 触发 1/n 分割；跨轮 3% / 0.4%。
- ITU Res.35（WRC-23 修订）：7 年期满后 2 年 10%、5 年 50%、7 年 100%，截止后 30 d 内报。Res.8 轨道容差（≤ 2000 km）：部署阶段远 / 近地点 ±70 km、倾角 2°；维持阶段 ±30 km、2°；连续超限不得超过 60 d。
- FCC Gen2 半年报六项：会合与机动、退役 / 筛除、再入、处置失效与 object-years、规避停摆、与 NASA 协作。2026-07 FCC Part 100：全部持照方共享星历，机动前共享星历与协方差，新里程碑框架。
- WRC-27（2027-10，上海）：EPFD 复审不是正式议项。

**⑧ 运营软件与自动化**
- 2020 AMA：日 5 TB 遥测、在轨 3 万多个 Linux 节点、全星座软件约每周更新、星上先判再下传。
- 2026 招聘：PB 级遥测平台；「command, control, and monitor thousands of assets」的 Web 运控应用；自动故障检测与响应（FDIR）；少人值守；轨控算法同时跑在星上与地面，先仿真、再在轨试验、再改构型；定轨流水线讲 Kalman、协方差真实性、阻力与密度、空间天气、仅测角定轨。

### 1.3 国内对照

- **国网**：ITU 资料 GW-A59 6080 + GW-2 6912 = 12992 颗；已部署 86.5° / 约 1175 km 与 50° / 约 1156 km 两壳；低轨 01–27 组（2024-12-16 至 2026-10-10），约 220 颗业务星。本次快照识别出的两壳与之吻合（§4.1）。
- **千帆**：一期 1296 颗、规划 1.5 万颗以上；约 256 颗（2026-09）；2025-07 报道 90 颗中 17 颗未到约 1070 km、滞留约 800 km，部分翻滚；2024-08 长征六号甲上面级解体产生 300 多个可跟踪碎片。快照里 49 颗长期低于工作壳与之吻合（§4.1）。
- **《卫星网络国内协调管理办法（暂行）》**（工信部无〔2025〕52 号，2025-05-01 施行）：协调地位按工信部收妥资料时间确立；NGSO FSS 与 GSO 之间符合 RR 第 22 条的免于国内协调；时限为 5 + 5 个工作日确认、2 + 1 个月出结论、逾期两次各隔 1 个月提醒后视为完成。

## 3 设计

### 3.1 定位与边界

「星座运管」管的是**一个星座工程从申报、部署、运行到离轨的全过程**。对象有三种，同一套界面：

- **真实星座**（Starlink / OneWeb / Kuiper / 国网 / 千帆……）：只用公开数据——CelesTrak GP / SATCAT（平台已有四级链路）+ 运营方补充星历 SupGP + 空间天气；
- **自己的设计**（生成器 / 轨道向导出的构型，或手填壳层）：用平台引擎推演；
- **两者叠加**：设计构型当「理想槽位」，真实星当「实际星群」，算偏差、缺口、补网。

| 做 | 不做（理由） |

### 3.3 槽位模型

设计构型按时间展开成理想槽位。式子与 `walker.js` 同源，只多 J2 长期项，使理想槽位与真实星同步漂移（否则过几天 RAAN 就对不上）：

```
Ω_p(t)   = Ω₀ + p·ΔΩ + Ω̇·(t − t₀)                      ΔΩ = raanSpan / P
u_p,s(t) = u₀ + s·360°/S + p·F·360°/(P·S) + u̇·(t − t₀)
Ω̇ = −(3/2)·n·J₂·(Rₑ/p)²·cos i
u̇ = n + ω̇ + Ṁ₀ ，ω̇ = (3/4)·n·J₂·(Rₑ/p)²·(5cos²i − 1)，Ṁ₀ = (3/4)·n·J₂·(Rₑ/p)²·√(1−e²)·(3cos²i − 1)
```

**实际星 → 槽位**：每个面一个 S×S 指派问题（Jonker–Volgenant），代价 = |ΔΩ|/w_Ω + |Δu|/w_u + |Δh|/w_h；先扣掉人工钉死的；分不到槽的星记为在轨备份。偏差读数五个：ΔΩ（°）、Δu（°，另折沿迹 km = Δu·a）、Δh（km）、Δe、Δi（°）。越出保持盒只用着色表达。

**高度口径必须单列**（本次实测撞到的）：引擎用 a − Rₑ（赤道半径），而申报 / 新闻口径多是「轨道平均大地高」，两者差 Rₑ·f·sin²i/2 —— i = 53° 时约 6.8 km，i = 97° 时约 10.6 km。实测 Starlink 某壳 a − Rₑ = 462.7 km，折成平均大地高约 469.5 km。设计表、识别结果、图上读数统一用 `altRef` 一个口径，悬停 `title` 给出另一口径的值。

### 3.4 生命周期状态机

代码与 McDowell 分类一一对应（§1.1），他的公开计数直接当标定集用（判据阈值 δ / x / N 拿他的分类表标定，§6）。

| 状态 | 代码 | McDowell | 有历史时的判据 | 单历元降级判据 |

| 计划 | `planned` | — | 设计槽位无星 | 同 |

状态带四样附属量：进入时刻、证据量（dh/dt、ṅ、阻力残差、检出机动数）、置信度（单历元降级判据给低置信度）、人工钉定（覆盖自动判定并留痕）。状态名是分类值不是判定，结果区可以显示（与 CLAUDE.md「不出现达标 / 受限」不冲突；待拍板第 7 条确认）。

**机动检出**：相邻两组根数之间，用阻力模型从 a(t₁) 预测 a(t₂)，与实测比；残差 > kσ 记一次机动。Δv 估计（近圆）：切向 Δv ≈ (v / 2a)·Δa，法向 Δv ≈ v·Δi（rad）。例：a = 6860 km 时 Δa = 1 km ↔ Δv ≈ 0.56 m/s。

**⑤ 交会**
- 筛查设置：主体（全工程 / 选中集 / 单星）× 次体（活跃编目 / 全编目 / 碎片组 / 自定义集）× 时窗（缺省 7 d）× 筛查体积预设（18 SDS 盒形四档：近地点 ≤500 km 为 0.4×44×51 km、500–750 为 0.4×25×25、750–1200 为 0.4×12×12、1200–2000 为 0.4×2×2；NASA 示例椭球 0.5×17×20 km；10 km 球）。本星座两颗都在壳的星之间可选不筛（SOCRATES 同口径：事件数 14.4 万 → 5.6 万）。
- 结果表：TCA｜主体｜次体｜次体类型（载荷 / 箭体 / 碎片）｜miss｜R / T / N｜相对速度｜Pc｜Pc 方法｜马氏距离｜协方差来源（CDM / 运营方星历 MEME·OEM·OCM / 历史合成 / 无协方差）｜星历龄（DSE）｜距今。按 Pc 档着色，阈值预设两套可切：NASA（红 1e-4 / 黄 1e-7）与 Starlink 现行（3e-7 + 脱靶距离）。
- **Pc**：缺省 Foster 2D（Elrod 加速），相对速度低或相遇时间长时按 CARA `PcMultiStep` 的判据逐级升到 2D-Nc → 3D-Nc → SDMC；无协方差时三选一：Alfano 最大 Pc（SOCRATES 口径，100 : 300 : 100 m 形状 + dilution）、Frisbee 单侧上界、由本机历史库按 COMSPOC 法合成的协方差（距 OD 历元 × 纬度幅角分箱）。TLE / GP 本身无协方差，单凭它只能做筛查（NASA 手册附录 E）。
- 详情：主 / 次目标体检表（周期、近 / 远地点、倾角、星历龄、可机动标志、HBR）、相遇平面图（协方差椭圆 + HBR 圆 + miss 矢量）、Pc 与 miss 各分量随 CDM 序列的演化。
- **规避**：权衡图「切向 / 径向 Δv × 执行时刻（含 TCA 前 N+½ 圈候选）→ Pc」色图；CW 解析给初值（沿迹分离 ≈ 3Δv·Δt，奇数半圈径向分离 4Δv/n），数值传播校核；缺省目标是 Pc 降 1.5 个数量级；选定方案 → 对全编目重筛，标出由此新增的超门限事件（「不得抬高其他会合」）→ 生成机动事件。
- 处置栏（用户填的数据，不是计算判定）：机动 / 观察 / 不处置 / 由对方机动 + 备注；超门限未处置的事件按原因记账（CDM 迟到 / 目标跟踪差 / 非合作机动 / 发射空窗 / 数据源中断 / 星上能力受限 / 磁暴），半年报直接汇总。
- 交换：CDM 导入（CCSDS 508.0-B-1 KVN / XML、TraCSS JSON），同一事件多条 CDM 按 `CONJUNCTION_ID` 式规则归并；导出 CDM、带协方差的 OEM、OCM 机动块（`MAN_BASIS = CANDIDATE / PLANNED`、`MAN_PURPOSE = COLA`）。本星座内部交会（面交叉区）单独一张统计。

**⑥ 环境**（空间环境与寿命）
- F10.7 / Kp / Ap 序列：观测 + 3 d Kp 预报 + 45 d 逐日预报 + 月预报（周期）；当前值读数。数据走 CelesTrak `SW-All.csv`（一份文件含全部，`F10.7_DATA_TYPE` 标 OBS / INT / PRD / PRM）或 NOAA SWPC JSON，与 `solarFlux.js` 同一套四级链路。
- 密度：NRLMSISE-00 的输入是前一日 F10.7、以当天为中心的 81 d 均值、7 元 Ap 数组（日 Ap + 当前及前 3 / 6 / 9 h 的 3 h ap + 前 12–33 h 与 36–57 h 均值）；预报段按 ap 预报误差给上下带（Gannon 风暴时 ap 的 0–3 d 预报低估 100–300）。
- 逐壳：密度、年阻力补偿 Δv、推进剂消耗（按工程里的质量 / 比冲）、剩余寿命。
- 离轨 / 失效星再入预测表（日期 + 不确定带）与衰减曲线；有 Space-Track 账号时叠 TIP 预报窗。
- 处置合规（数值，着色）：退役 / 失效星预计在轨年数 vs 规则年数（FCC 5 年 / ESA 5 年 / IADC 25 年三列）；失效 object-years 台账（FCC 上限 100）。
- 磁暴推演：给 Ap 峰值与持续时长 → 各壳密度放大、低轨星高度损失与再入数；Ap 跳变超过设定值时，已出的交会筛查结果标「过期」并排队重算。2022-02 那次（49 颗 / 210 km 近地点 / 38 颗再入）作回测。

**⑦ 地面**
- 关口站 / 测控站：来自地球站库，CityPicker 选址。
- 每星关口站可见率、最长无关口站时长；地图图层画关口站可见圈（按最低仰角）。
- 测控接触计划：AOS / LOS 甘特（复用 accessWindows）、每日接触次数、最大间隙。
- 关口站日凌：NGSO 过境中太阳–卫星夹角小于门限的时段（新引擎，GSO 仍走日凌模块）。
- 站址分集可用度（复用多站可用度，Poisson–binomial）。

**⑧ 网络**
- 蜂窝网格 + 需求导入（CSV：经纬度 / 终端数 / 速率），按地区汇总。
- 调度（缺省 15 s 一拍，相位 :12 / :27 / :42 / :57 可设）：可见星（仰角 ≥ ε_min，ε_min 可按纬度分段——Starlink 许可为 62°N 以南 25°、以北 5°；离 GSO 弧 ≥ α；关口站可达）× 星上波束数 × 波束容量 → 分配；选星偏好按权重可调（仰角、方位、光照、星龄、负载），缺省权重按公开反向工程结果标定（被选星仰角中位数比未选高 22.9°）。出参：逐格供给 / 需求 / 利用率 / 不可服务时长（主窗口热图）、每星负载分布、每小时切换次数、与重配时刻不对齐的切换数。
- 同区同频波束数 Nco 是参数（Gen2 原许可 1，2026-01 美国境内豁免 ≤ 8）；GSO 排除区同时存「规避半角」与「排除区全宽」两个口径（FCC 26-26：最小规避角 3° = 6° 排除区），界面只显示一个，另一个进 `title`。
- 载荷模板：Ku 下行 8 × 240 MHz（10.7–12.7 GHz，信道间隔 250 MHz）可一键套用；波束数 / 单星容量按版本（V2：下 192 / 上 144；V3：2048 / 2048）。
- 波束容量 = 链路预算算出的 C/N → MODCOD 库查频谱效率 × 波束带宽（复用 NGSO 链路预算引擎与 MODCOD 库，这是 STK 类工具没有的一环）。
- GSO 弧规避：逐（格, 星, 拍）用 `alphaAndDeltaLong`（`pfdmask/alphaGeometry.js:211`，S.1503 §D6.4.4.1 的 α 角）做门控，与 PFD 掩模生成器的 `maskAlpha0Deg` 同一个角；出参是规避带来的可服务时长损失与容量损失（逐格、逐纬度带）。
- 频率复用：波束频率 / 极化分配沿用频率计划数据模型。

**⑨ 合规**

- ITU 轨道容差（Res.8）：逐星对照申报轨道——部署阶段远 / 近地点 ±70 km、倾角 2°（70–100 km 或 2–3° 须技术论证）；维持阶段 ±30 km、2°；连续超限天数（上限 60 d）。数据就是台账里的 Δh / Δi。
- PFD / EIRP 掩模：按壳引用 PFD 生成器的出包（每壳一个作业）；GSO 弧规避角与掩模的 α₀ 对齐读数；处置合规汇总。
- 运行报告：月报 / 半年报，Word + Excel；半年报按 FCC Gen2 那六项组织（会合与机动、退役 / 筛除、再入、处置失效与 object-years、规避失效、协作），全部只给数值；版式沿用 SSA 报告已拍板的样式规范（纸面恒浅、三线表、600 dpi 成图）。
- 国内协调计时（待拍板）：按《卫星网络国内协调管理办法（暂行）》的时限给每条协调记录算到期日（5 + 5 个工作日确认、2 + 1 个月出结论、两次 1 个月提醒）。

- **攒**：每次 omm.js 成功取到一组（缓存优先 + 后台联网那条链路），把新出现的（NORAD, EPOCH）追加进 `userData/data/elemhist/<group>/<yyyy-mm>.bin`。只攒工程里引用到的组。不为攒历史多发一次请求——取数频率仍是现在的每组每天至多一次，在 CelesTrak 纪律之内。
- **记录**：NORAD u32 + EPOCH f64 + n / e / i / Ω / ω / M / B* / ṅ 八个 f32 = 44 B。Starlink 1.1 万颗、每星每天约 2 组 → 约 1 MB/天，全精度留 90 d，之后每星每天抽 1 组 → 约 180 MB/年；可设上限。
- **补**：导入 Space-Track 按年打包的 TLE / GP 历史（用户自己的账号自己下；`GP_HISTORY` 官方要求每个目标终身只拉一次、下到本地后不重复下）或一个 TLE 文件夹，一次补齐历史。
- **用**：`orbitPos` 加一层「历史表」：查询过去时刻时取最近的一组根数，而不是拿最新根数往回推（往回推会穿过所有机动）。这条顺带让全平台能「回到过去某天」看星座（部署回放、过去某日的可见性）。

**编号与格式**：CelesTrak 5 位编目号 2026-07-11 用尽，新目标从 100000 起、不再提供 TLE（快照里 Starlink 最大号已到 101030）。新模块一律按 9 位 `NORAD_CAT_ID` 处理，OMM / CSV 为主；TLE 只在导出时按 Alpha-5 写（现有 `ephemExport` 已封顶 339999）。

## 8 风险与诚实边界

1. **数据精度**：GP / TLE 没有协方差，LEO 历元后 72 h 内位置误差约 0.6–3 km（NASA 手册附录 E）。只用 GP 时交会是筛查级；要据此做处置得有运营方星历（MEME / OEM / OCM）+ CDM。界面上 Pc 方法与协方差来源各占一列，绝不混成一个数。
2. **没有遥测**：健康只能从轨道行为推断。「失效」判据会把长期不机动但健康的停放星判错 → 置信度 + 人工钉定。
3. **Starlink 内部算法不公开**：调度、选星、波束、容量是同类模型，参数取公开值（测量论文、FCC 文件、分析师模型），用于方案比较，不代表 Starlink 实际运行。
4. **高度口径**：a − Rₑ 与平均大地高差 7–11 km（§3.3），识别结果与申报壳对应要按（i, h, Ω̇）三者匹配。
5. **历史库从零攒**：头 30 d 只有单历元判据（偏差见 §4.2）；可导入 Space-Track 历史补齐。
6. **算力**：筛查与调度依赖 Worker；老电脑限并发、可取消、有进度，口径照 2026-10-15 低端机性能审查。
7. **数据条款**（商用前要定）：
   - CelesTrak 使用政策没写再分发条款——**平台现有的随包快照与 COS 众包镜像都属于再分发**。Space-Track 对「基本 SSA 数据」（GP / SATCAT / 衰减）有带引用的总括许可，CelesTrak 的 GP 源自它。建议商用前在关于页与报告加数据来源引用，并向 CelesTrak 书面确认。
   - SpaceX MEME 许可未写明：只按需下载，不入包、不上云镜像。
   - McDowell 统计 CC-BY：只进测试，署名。
   - NRLMSISE-00 用 Apache-2.0 的版本或自行移植；CARA 工具（NOSA）只当对拍数据。
8. **与已回退 / 已否决事项的边界**：不碰星间链路仿真（§9 问）、频率管理、CnC、参数总览、应用场景仿真、3D 相机飞行；不做 S.1503 EPFD 自校验；网络页如要算 ACM 统计效率，取回退的频率管理模块留下的 S.2131 结论（只取算法，不取界面）。
9. **真实星座名**：界面与报告出现 Starlink / 国网 / 千帆等名称属于公开数据分析，SSA 报告已有先例；所有者中文名照平台主权红线。
10. **工作量是估计**：3.6 万行里 S4（交会）与 S6（网络）的验证可能超出；每步独立可交付、可回退。
